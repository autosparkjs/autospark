# ADR-0107：$slots 插槽注册表与动态出口

- 状态：已采纳（2026-10-12 grilling 共识落盘，实施随本 ADR 进行）
- 日期：2026-10-12
- 关联：ADR-0056（插槽机制——出口/内容/归属容器三面）、ADR-0029（$scopes 保留键域）、
  ADR-0062（shell 机制——live 活体段）、ADR-0081（组件继承覆盖）、ADR-0084（x-super 叠加）、
  ADR-0053（组件数据边界——内容调用方视图）

## 背景

ADR-0056 的整套投影体系建立在「出口集合编译期静态已知」之上：出口名是属性参数字面量
（`x-slot:header`）、出口清单从定义模板静态推断（`ComponentDef.slots`）、内容收集按
清单校验（无对应出口 warn + 丢弃）、内容段一次性投影。组件无法表达「出口集合由状态
决定」的场景——tabs 组件为每个标签渲染一个出口、出口数量与名字由数据驱动、组件需要
感知调用方提供了哪些名字来编排布局。

## 决策

### 1. 元数据注册表 + 出口模型（否决函数式 slot）

`$slots` 是**实例级插槽内容注册表**（元数据视图），渲染仍走 `x-slot` 出口——内容收集、
调用方作用域求值、形参注入、fallback、x-super 机制原封复用（DRY），唯一改动是出口名
的解析方式。否决「`$slots.name` 即可调用模板」（Vue renderless 风格）：命令式渲染与
「编译期重建运行树」架构正交冲突，迁移代价极大；否决元数据 + 可调用混合形态（YAGNI）。

### 2. 动态出口名：值承名、值双形态

出口名的第四种写法（既有三种 `x-slot` / `x-slot:名` / `x-slot.修饰` 语义不变）——裸
`x-slot` 的**值**从语义空白转正：

- 值求值为**字符串** → 即出口名：`x-slot="t.key"`；
- 值求值为**对象** → `{ name, params }`：name 必填（出口名）、params 即既有形参取值
  语义（求值后按内容解构键抽取注入）：`x-slot="{ name: t.key, params: { item: t } }"`。

单一值通道形态分流（`typeof` 判定），零新属性、零新机制。带冒号形态的值通道仍专属
形参取值（`x-slot:名="值"` 不变），互不干扰。源码值**空白**不算动态名（维持现行为：
默认出口 `default`，零破坏）。

### 3. 编译期求值一次、静态绑定；params 保持响应式

出口名在 created（编译期）经 `scope.read` 求值一次后固定（x-for 迭代 locals 可用），
`name` **不响应式**——出口名变化靠 x-for key 重建子树表达；「名变化原地换投影」的
运行时迁移机制被否决（须拆旧投影按新名重编译，复杂度高且场景存疑）。`params` 走既有
watch 通道保持响应式（与静态出口形参一致）：watch 整个值表达式，回调抽取 `value.params`。

### 4. 多实例独立编译

同一内容段被 N 个出口消费（x-for 迭代产生、或兄弟动态出口同名求值）→ N 份独立克隆
编译（各自 scope/watcher/DOM）——x-super「多次出现各自展开」先例的推广。静态出口
「同名首个胜 + warn」规则**不适用于动态出口**：该规则防的是同一模板重复声明同一静态
出口的笔误；动态出口的多实例是合法语义（Q4）。

### 5. 组件路径全量收集

x-component 的内容收集跳过出口清单校验（`collectSlotSegments` 新增 `skipValidation`
选项）：命名段全量入注册表，未被消费的段静默闲置**不 warn**——「是否有动态出口消费」
只有组件知道，收集侧无从判定。**fallback-only 的名字不存在于注册表**（动态出口的名字
由调用方内容决定，组件无法枚举没被提供的名字）。覆盖物路径（`_collectSlotContents`）
维持清单校验现状，**零回归硬约束**。

### 6. `$slots`：保留键 + 冻结快照 + 最小条目

- 组件实例域**框架保留键**（`$scopes` 同风格，ADR-0029），挂实例 scope 聚合视图：
  `getContext` 的 get/has 注入（最高优先级，不被数据遮蔽）、set 拦截（warn 一次 +
  只读）；聚合视图快路径（无 locals/data 直返父视图别名）须包含 slotsRegistry 条件；
- 条目最小化 `{ name: string }`——`params` 形参键表无真实消费场景（出口渲染时形参
  注入由引擎内部完成），后续按需再扩（删字段是破坏性变更，故 v1 从窄）；
- `default` 段入注册表（完整内容视图；意外卷入遍历只发生在作者自己写的遍历里，可预期）；
- `Object.freeze` 冻结（条目 + 整表），实例生命周期内不变（非响应式）——「动态」是
  出口数量的动态，不是内容集合的动态；
- 无内容 → 恒注入冻结空对象（`Object.keys($slots)` 空数组，遍历友好）；
- stash 两处（`instantiateComponent` / `instantiateDetachedComponent`）同步构建——
  覆盖物 shell 经 detached 路径自动获得（其段集仍受静态清单收集约束，与决策 5 的
  边界一致）。

### 7. live 活体段互斥

动态出口消费到 `mode: "live"` 段（ADR-0062：已编译活体组件实例 DOM，不可克隆、不可
再编译、只能挂载一处）→ warn + 按无内容处理（渲染 fallback）。活体段只产于
overlay/shell 编程式构造，与组件 `$slots` 场景天然不相交，此为纯防御。静态出口的
live 直挂通道不变。

### 8. 无效出口名降级

求值结果非法（null / undefined / 数字 / 求值空串 / 对象缺 `name` 或 name 非非空字符串）
→ warn + 按无内容处理：出口元素保留、fallback 子树正常编译渲染（与「出口存在但无
内容」同一出口，降级路径最短）。运行态 `data-slot` 标记无效名不写。否决静默回退
default（违反 warn 纪律）与整体剪枝（fallback 语义断裂）。

### 9. 静态边界：内容名恒静态、继承覆盖不支持

- **内容名恒静态**：内容侧 `x-slot:名` 的名恒写在属性名里（属性名物理上无法承载
  表达式，内容收集编译期按属性名分段）——调用方静态决定「有哪些名字」，组件动态决定
  「渲染哪些、渲染到哪」。内容名动态化不立项（YAGNI）；
- **继承覆盖不支持动态出口**（ADR-0081 维持父静态清单校验）：子定义误写动态出口标记
  会按内容侧分段规则解读——值非空裸 `x-slot` 非 `{}` 形态，命中既有「形参须为简单
  解构形」warn 后被并进默认覆盖段。已知缝隙：继承 + 动态出口为罕见组合，不在分段
  逻辑上打补丁（避免「非 `{}` 形态裸标记」行为的全量回归）。

### 10. 静态清单收窄

`ComponentDef.slots` 语义收窄为「静态出口清单」：`collectOutletSlots` 跳过值非空的
裸 `x-slot` 元素——动态出口不入清单、不参与同名去重、不剥标记属性（须留给
SlotDirective 实例化时动态解析）。

## 后果

- 实施落盘物：`utils/slot.ts`（`skipValidation` 选项 + `buildSlotsRegistry`）、
  `directives/x-slot.ts`（值双形态解析 + live 防御 + 无效名降级）、`engine/scope.ts`
  （`slotsRegistry` 字段 + 聚合视图保留键注入）、`engine/compile/compiler.ts`（两处
  stash 点同步构建）、`engine/compile/collect.ts`（静态清单排除动态出口）、
  `directives/x-component.ts`（组件路径全量收集）；
- 典型用法：组件内 `x-for` 遍历 `$slots`（`Object.keys($slots)` 取名集），循环体内
  `<div x-slot="名" x-slot 形参对象>{ fallback }</div>`——出口数量与名字由调用方
  内容与组件状态的交集决定；
- 出口名求值上下文为出口所在 scope（组件模板内的组件数据域/外层 x-for locals 可见）；
  非 `$slots` 保留键作用域（非组件实例域）读 `$slots` 得 undefined，误用由表达式
  自然报错暴露，不做额外防御；
- 测试落盘：动态名投影（字符串/对象形态）、params 响应式、x-for 多实例、无效名降级、
  live 互斥、注册表冻结与 default 段、全量收集、静态清单排除——覆盖物路径回归由
  既有 overlay/覆盖物测试保障。

## 已知边界（不做）

- 出口名响应式跟随（决策 3 否决）；
- 内容名动态化（决策 9 否决）；
- 继承覆盖动态出口（决策 9 维持现状 + 已知缝隙）；
- 覆盖物路径收集放行（零回归约束下维持清单校验；二期若放行是纯放宽，不破坏本期语义）；
- `$slots` 条目携带 `params` 键表（无消费场景，YAGNI）。
