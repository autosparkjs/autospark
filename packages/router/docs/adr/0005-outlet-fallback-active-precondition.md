# ADR-0005: 出口回退与渲染域激活前提

- 状态：已接受（Accepted）
- 日期：2026-10-14
- 关联：ADR-0002（engine 渲染管线）、ADR-0003（outlet props / keepAlive 默认翻转）、ADR-0004（加载域公共层跳过）

## 背景

嵌套路由逐级渲染时，第 i 层视图的挂载出口 = 第 i-1 层视图容器内的嵌套出口（`x-outlet` 编译产物）。当某层视图未声明子出口（如三级详情页的父列表模板漏写 `<div x-outlet>`），原实现记 error「无法找到出口，跳过渲染」后 `continue`——该层**及其后所有更深层**永久跳过，详情内容无声消失。深链（如 `/products/tablets/t2/a/a/...`）在出口链短于匹配链时同理整链哑火。

排查中还确认一个配套缺口：渲染域公共层跳过是「什么都不做」——`active` 全库只在挂载路径写入、无去激活逻辑。从 `/products/tablets/t2` 后退到 `/products/tablets` 时目标链全部落在公共前缀，详情视图容器无人休眠，**残留在列表下方**（URL 与显示不符）。回退机制会让该缺口恶化：详情回退置换列表后，后退连列表都无法恢复。

## 决策

### 决策 1：出口回退（outlet fallback）

出口定位失败**不再终止本层渲染**：不推进 `currentOutlet`，本层视图沿用上一层出口挂载（置换上一层视图）；更深匹配层继续在同一出口逐级置换，**最深者胜**。日志降级为 warn（含路径链）。

三条衍生语义：

- **自愈向下**：回退挂进的视图自带 `x-outlet` 时，更深匹配层在其容器内重新找到出口、正常向下扎根——回退只发生在「缺出口」的那一层，不传染。查找协议（`_awaitNestedOutlet(currentOutlet, 上一层hash)`）不变，回退即「不推进」。
- **DOM 真相检测**：出口有无以挂载后的运行 DOM 为准（沿用既有有限微任务重试，仍 miss 才回退），不做视图 HTML 文本预判——动态模板/绑定出口下预判不可靠。
- **根出口无回退**：宿主内连根出口都没有时无处可退，维持 error + 终止渲染（该分支语义不变）。

unmatched 尾段（URL 深度超过路由表）不产生渲染层（`route: undefined` 项被渲染循环跳过），最深匹配层落位回退出口——`/products/tablets/t2/a/a/...` 在两级出口下即 t2 详情渲染进二级出口。

### 决策 2：渲染域激活前提（active-view precondition）

公共层跳过条件从 `i < commonRouteIndex` 收紧为 `i < commonRouteIndex` **且本层视图仍是其出口的当前激活视图**（无视图层照旧跳过）。激活前提不成立时正常执行挂载——data/view signal 已由加载域备好（ADR-0004），零网络成本，且与既有复用路径自然合流：keepAlive 视图命中同 hash 就绪条目走「仅激活」（`isReuse` 分支，不触碰 DOM 运行态）；ephemeral 视图重挂恢复。

典型触发：回退置换后后退（出口 active 指向更深视图 → 列表重挂恢复）；后退裁剪后某层曾被置换。

### 决策 3：裁剪清理（trimmed-layer cleanup）

from 链比 to 链长出的层级（后退裁剪），其视图仍激活在挂载出口中——从渲染终点出口起逐级下探：按被裁层视图容器锚点（`data-view-hash`）找到容器，向上取最近出口祖先（该层视图的挂载出口），清空其 `active` 休眠残留（keepAlive 条目保留可复用，ephemeral 容器随 x-show 隐藏）。容器不存在（已被置换、随旧 DOM 销毁）即无残留，链式中止。

## 备选方案

- **维持「找不到出口即跳过」+ 强化报错**：否——把模板缺出口的容错责任压给每一个下游视图作者；深链整链哑火对用户不可见、对开发者难定位。
- **视图 HTML 预判消除中间层闪烁**：否——`x-outlet` 可能经绑定/动态模板出现，文本预判不可靠；ephemeral 模式下中间层置换存在瞬时可见的可能，接受之（keepAlive/tabs 模式两视图同列无闪烁）。
- **回退只退一级、深层继续报错**：否——回退语义本就是「沿最近可用出口」，逐级置换后最深者胜是同一机制的连续应用，单独「退一级再报错」制造不一致。
- **裁剪清理改为恢复激活**（把残留出口 active 指回父层视图）：否——残留出口是被裁层视图内部的出口，其语义归属被裁层而非父层；清空休眠 + 父层激活前提重挂已覆盖恢复路径，双写激活态反而引入两处真相。

## 后果

- 正面：模板缺出口从「整链哑火」变为「优雅降级到最近可用出口」；后退裁剪不再残留深层视图；回退置换后列表可正确恢复（keepAlive 零成本复用）。
- 代价：ephemeral 模式下回退链的中间层有短暂挂载-置换（DOM 真相检测的代价）；渲染域跳过判定新增一次出口数据域读取（`_isOutletActive`，轻量）。
- 裁剪清理按被裁层 hash 锚点查找，依赖 `matched.hash` 唯一性（ADR-0004 决策 4 的既定语义）。
