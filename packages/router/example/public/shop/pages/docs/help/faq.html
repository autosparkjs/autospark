Q1：收货后多久内可以无理由退货？

自签收次日起 7 天内，商品完好且不影响二次销售的，可申请无理由退货。详情见「退换货流程」。

Q2：如何查询设备的保修状态？

进入「服务 → 保修查询」，输入设备序列号或 IMEI 即可查看激活日期、保修剩余天数与历史维修记录。

Q3：手机进水了应该怎么办？

请立即关机，切勿充电或用吹风机加热；用干布吸干表面水分后尽快送修。进水属意外损坏，基础保修不覆盖，手机保险用户可正常理赔。

Q4：为什么充电速度比宣传的慢？

120W 峰值功率仅在电量 20% 以下且使用原装充电器与线材时触发；电量超过 50% 后自动进入涓流充电保护电池。

Q5：旧手机的数据如何迁移到新机？

开机向导中选择「从旧设备迁移」，同品牌设备点对点直传；跨平台可使用「麒麟换机」App，或到店享受 30 分钟专业迁移服务。

Q6：系统更新失败提示空间不足怎么办？

清理「文件管理 → 安装包」与不常用应用后重试；也可在「设置 → 系统 → 手动更新」中选择「下载并安装（保留数据）」的完整包模式。
