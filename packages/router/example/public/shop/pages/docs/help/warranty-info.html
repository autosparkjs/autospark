保修政策

25,630 次浏览·更新于 2024-01-08

保修期限

部件保修期限备注
整机主机12 个月自激活之日起算
电池12 个月容量衰减至 80% 以下可免费更换
充电器 / 数据线12 个月非人为损坏
耳机等附件6 个月以保修卡为准

保修范围

  • 属保修范围：非人为硬件故障、性能异常、出厂缺陷；
  • 不属保修范围：进水、跌落等人为损坏，擅自拆机，超出保修期，序列号磨损无法辨认。

索赔流程

  1. 在「服务 → 保修查询」确认设备在保修期内；
  2. 提交维修申请并描述故障现象；
  3. 邮寄或送修至官方服务网点；
  4. 检测确认后免费维修并寄回（往返运费官方承担）。

💡 购买「手机保险」可将意外损坏纳入保障，详情见服务页面的保险方案。
