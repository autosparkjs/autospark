退换货流程

14,230 次浏览·更新于 2024-01-03

七天无理由退货

自签收次日起 7 天内，商品完好、配件齐全且不影响二次销售的，可申请无理由退货。已激活并使用超过 24 小时的设备需扣除激活折损费。

退货流程

  1. 在「我的订单」中选择订单，点击「申请售后」；
  2. 选择退货原因，提交申请（1 个工作日内审核）；
  3. 审核通过后按指引寄回商品，填写快递单号；
  4. 仓库验收合格后，原路发起退款。

换货说明

  • 质量问题换货：15 天内免费换新，往返运费官方承担；
  • 非质量换货：仅支持同型号颜色更换，需补齐差价；
  • 换货周期一般为 3-5 个工作日（不含物流时间）。

退款时效

支付方式退款时效
支付宝 / 微信验收后 1-3 个工作日
银行卡验收后 3-7 个工作日
分期付款取消分期后按原渠道退回

⚠️ 退货请保留完整包装与赠品；赠品缺失将按原价从退款中扣除。
