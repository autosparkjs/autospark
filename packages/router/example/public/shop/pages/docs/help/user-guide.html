使用指南

18,920 次浏览·更新于 2024-01-10

核心功能速览

功能入口说明
暗色模式控制中心下拉控制中心点击「深色」一键切换，支持定时开启
分屏多任务多任务卡片菜单长按应用卡片选择「分屏」，上下同时运行两个应用
游戏空间桌面「游戏空间」免打扰、性能模式、录屏三合一
NFC 门禁设置 → NFC模拟实体门禁卡，熄屏碰一碰开门

常用手势

  • 从屏幕底部上滑返回主页；上滑停顿进入多任务；
  • 从屏幕左右边缘内滑返回上一级；
  • 三指下滑截屏；三指长按识别全屏文字；
  • 双击亮屏 / 双击熄屏（设置 → 指纹与手势中开启）。

拍照模式

  • 人像模式：f/1.4–f/16 可调光圈，营造背景虚化；
  • 夜景模式：手持多帧合成，暗光拍摄建议稳定 2 秒；
  • 专业模式：手动调节 ISO / 快门 / 白平衡，支持 RAW 输出。

电池优化技巧

  1. 开启「智能刷新率」，静态画面自动降至 60Hz；
  2. 对不常用应用开启「冻结后台」；
  3. 夜间启用「充电保护」，充满 80% 后暂停至早晨续充。

💡 提示：更多进阶技巧可在「设置 → 使用技巧」中按场景查阅。
