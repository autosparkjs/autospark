autospark.autocomplete

自动补全输入（ADR-0027）：真原生 input（复制 input 结构而非嵌套，field 盒饰） + 输入驱动建议面板（x-popover 机制，select 同款）。建议源双通道： :suggestions 本地包含过滤 / fetch 异步（action 名通道， 防抖默认 300ms）；键盘：上下选建议 / Enter 确认 / ESC 关；选中派发 select + change（detail = { value }）。

跨插件依赖：建议面板呈现须同时加载 autospark.overlay.js（x-popover 指令）。

基础用法（:suggestions 状态引用 + x-model 双向）

当前值：{{ q1 || '（空）' }} —— 聚焦展开全量，输入即过滤。

异步建议（fetch = action 名，debounce 防抖 + 次序守卫）

连续输入防抖合流；回包过期丢弃（期间又有新输入）。action 三入口任一注册均可 （本例经构造器 options.actions）。

select / change 事件消费（detail = { value }）

最近选中：{{ picked || '（未操作）' }}（select 仅在选中建议时触发）。

尺寸档位（主题通道 data-size）

档位属性挂在任意祖先容器即触发区整片生效；面板在 body 容器渲染，跟随页面级主题档位（局部容器档位不覆盖弹层——与暗色边界同构）。
