autospark.page-header

页头：title / subtitle 标题对 + back 返回钮（false 缺省 / true 图标钮 / 文案字符串 = 图标 + 文案，click 派发 back 冒泡事件）；slots：extra（右侧动作区）/ 默认（内容 区）。纯结构件，无 i18n 文案。

基础用法（back 文案形态）

页面内容写在默认插槽（内容区），空则不占位。

back=true 图标钮 + extra 右侧动作区

extra 命名插槽投影到头行右缘；back=true 为纯图标钮（aria-label 以标题自描述）。
