autospark.list

数据驱动列表容器：items 经内层 x-for 渲染 + row 作用域插槽自定义行 + 空态 （autospark.empty 组合）+ loading 覆盖层 + bordered / split + virtual 虚拟滚动。

基础（默认行：label/title/name/value 四键探测）

items 须状态引用注入（字面量数组触发 props 更新死环——已知引擎缺陷规避）。

row 作用域插槽自定义行（{ item, $index } 解构 + 行内事件原生冒泡）

最近选中：——行内 @click 在调用方作用域求值。

空态（autospark.empty 组合兜底 + empty 插槽重载）

loading 覆盖层（引擎 x-loading 组合）

无边框 / 无分隔线

virtual 虚拟滚动（10000 项，须同页引入 autospark.virtual.js）

定高滚动容器（--asc-list-virtual-height 可覆盖）；只渲染可见窗口 + 缓冲项。

暗色态（容器 data-dark）
