autospark.input-number

数字输入框（原生增强）：inputmode=decimal 原生控件 + 步进钮组（上/下，键盘 ArrowUp/ArrowDown 同义）；min/max 夹取、step 步长、precision 固定小数位、 controls 开关；change（blur/Enter 归位）事件 detail = { value }； 值通道走 x-model 兼容协议（宿主 x-model 直写，数字语域）。

基础用法（x-model 双向 + 步进）

当前值：{{ qty }}（点步进钮 / 方向键 / 直接输入）

step 步长 + precision 小数位

0.1 步进、两位小数：{{ price }}（blur 归位规范文本）

controls=false（纯数字输入形态）

尺寸档位（主题通道 data-size）

档位属性挂在任意祖先容器即整片生效（高度随档联动，无自有尺寸属性）。

状态色与禁用（status / disabled / readonly）

change 事件（blur/Enter 归位确认）

change detail.value：{{ score }}（超界输入 blur 夹取归位）

暗色态（容器 data-dark）
