autospark.affix

固钉（组件库 P4 other 件，ADR-0030）：滚动过 offset 阈值后内容 fixed 吸附视口 （position=top 吸顶缺省 / bottom 吸底）；原位占位撑高防跳动 + change 冒泡 detail = { fixed }。与 float-button （fixed 悬浮动作钮）/ anchor（滚动高亮导航）正交——本件是内容区固钉吸附。

吸顶（offset=80）

吸顶操作条 {{ fixed ? "已固定" : "随流" }}

吸底（position="bottom"，offset=120）

吸底操作条{{ count }} 次翻转

元素名写法 <x-affix :offset="80"> 经 precompile 变换折叠 props； 数值/字符串静态属性直写、响应式走 :属性 绑定。

区块一

向下滚动：顶条越过 80px 吸附视口顶、底条越过 120px 吸附视口底。

区块二

占位元素撑高原位高度（脱流前几何快照），滚动不跳动。

区块三

回落即恢复随流；change 事件同步翻转计数。
