autospark.card

卡片容器：header（title / header 槽 / extra 槽）+ body（默认插槽）+ footer 槽、 边框 / 悬停浮起 / 可折叠头部。阴影档位走 theme 手动通道 data-shadow。

基础卡片（title + body + footer）

卡片内容：默认插槽即 body 出口，投影内容为直接子级。
指令值形态写法（与元素名形态等价）。

header / extra 槽

header 槽整体重载标题区；extra 槽落头部右缘。

无边框（bordered=false）与悬停浮起（hoverable）

无边框卡片（阴影仍随 data-shadow 档位）。
鼠标悬停：边框点亮 + 阴影抬升。

可折叠头部（collapsible）

点击标题区（含箭头）切换折叠：body / footer 随之显隐（x-show 通道，DOM 保留）。

外部可经 @collapse="open = $event.detail.collapsed" 监听翻转（detail = { collapsed }）； collapsed 亦可外部受控驱动。

纯头卡片（body 空）与暗色态（容器 data-dark）

theme 在场时变量自动跟随暗色；无主题时走暗色兜底字面值。
