autospark.space

间距容器组件：间距档位（size）、排列方向（direction）、交叉轴对齐（align）、 换行（wrap）。纯样式容器，子元素正常编译。页面骨架窗格分割用 layout 指令族。

水平排列（缺省）与间距档位（size）

large 按钮 标签

档位名走 CSS 变量档（--x-spacing-* 标尺五档）；size: 24 为 px 数值、size: '1.5em' 为任意 CSS 值、size: [24, 8] 为 [水平, 垂直] 两轴。
