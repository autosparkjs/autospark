autospark.color-picker

颜色选择器（ADR-0028）：触发器 = Field 盒饰 + 色块预览；取色面板自绘 HSV 模型 （SV 面板 CSS 双层渐变 + H 条七色谱 + 预设色板 + hex 输入，零第三方库），呈现复用 x-popover 指令机制；值域 #rrggbb（简写/无 #/大小写自动 归一，非法归黑）。拖拽实时改色、提交恒在松手（change 不逐帧派发）。

跨插件依赖：面板呈现须同时加载 autospark.overlay.js（x-popover 指令）。 示例统一元素名组件写法（ADR-0117）。

基础用法（x-model 双向）

当前色：{{ color }}（宿主 x-model 直写；hex 输入支持 #rgb 简写）。

预设色板（presets 状态引用注入）

预设点击即应用（高亮当前色、不关面板——连续试色）。

change 事件消费（detail = { value }）

最近确认：{{ picked || '（未操作）' }}；name 透传 hidden 载体直提交。

尺寸档位（主题通道 data-size）与状态色 / 禁用

面板在 body 容器渲染——尺寸档位对面板同样生效（字号随档）。
