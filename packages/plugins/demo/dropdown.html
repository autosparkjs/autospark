autospark.dropdown

下拉菜单（ADR-0027）：动作触发型轻量菜单——触发区 = 默认插槽（任意内容，包裹交互）， 面板复用 x-popover 机制呈现；菜单项语义自持（不嵌套 menu：menu 是页面 导航区常驻组件，本件即点即走）。items 双形态（:items 状态引用 / <x-dropdown-item> 声明）；键盘：上下漫游 + Enter 触发 + ESC 关。

跨插件依赖：菜单面板呈现须同时加载 autospark.overlay.js（x-popover 指令）。

基础用法（:items 状态引用 + 默认插槽触发区 + select 事件）

最近触发：{{ picked || '（未操作）' }}（detail = { key, item }）

子元素声明形态（<x-dropdown-item>，含 icon / divided / danger / disabled）

文字触发区（hover）▾

缺省 trigger = hover（antd 同款）；分隔线 / 危险色 / 禁用逐项声明。

placement 定位（popover at.placement 12 方向透传）

尺寸档位（主题通道 data-size）

档位属性挂在任意祖先容器即触发区整片生效；面板在 body 容器渲染，跟随页面级主题档位（局部容器档位不覆盖弹层——与暗色边界同构）。
