autospark.menu

导航菜单：items（{ key, label, icon?, disabled?, children?[] }[]，状态引用）或 <x-menu-item> 子元素声明（含一层嵌套 children）双形态；受控 value （el.value 桥 + change detail={value}）；子菜单点击展开（祖先链自动展开）； mode 双形态 + collapsed 图标条。

基础用法（vertical 缺省：子菜单点击展开 + x-model 双向）

带 children 的父项点击展开/收起；激活值指向子项时祖先链自动展开。

horizontal 横向形态（子菜单 hover 浮层下拉）

collapsed 垂直收起为图标条（子菜单右飞浮层）
