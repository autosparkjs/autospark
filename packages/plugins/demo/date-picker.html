autospark.date-picker

日期选择器（P3 时间族，ADR-0025）：触发器 = Field 盒饰形态（input/select 同款 chrome），内部日历面板（月视图 6×7 grid + 月份切换 + 今天快捷）复用 x-popover 指令机制呈现；值通道走 x-model 兼容协议（宿主 x-model 直写，"YYYY-MM-DD" 字符串语域）+ 内嵌 hidden 载体原生直提交。 键盘：方向键日间漫游（跨月翻页）/ PageUp/PageDown 切月 / Enter 确认 / ESC 关。

跨插件依赖：面板呈现须同时加载 autospark.overlay.js（x-popover 指令）。

基础用法（元素名写法 + x-model 双向）

当前值：{{ d1 || '（空）' }}；视图归位到值所在月（无值落当月）。

clearable / 状态色 / 禁用 / 只读
