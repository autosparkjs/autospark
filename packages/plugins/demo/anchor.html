autospark.anchor

锚点导航：items 数据驱动（{ key, label, href? }[]，状态引用注入）或子元素声明 （<x-anchor-item> 静态标量）两形态；scroll 监听高亮当前锚（offset 判定线， 全未达线不高亮）；点击平滑滚动到锚（不写 hash——纯滚动语义）；change 冒泡 detail = { key }。

affix 固定侧栏（滚动联动高亮 + 点击平滑滚动）

右侧固定锚点跟随滚动高亮当前区块；当前锚 key：{{ cur }} （外层 @change 回写）。吸顶导航场景可加 offset 判定线补偿（本例 offset=0）。

概述

锚点导航适用于长文档页：侧边列出各区块入口，滚动到哪高亮哪，点击平滑回到该区块。

用法

items 恒经状态引用注入（secs 为页面状态）；href 缺省 key 作锚 id（#key）。

API 参考

props：items / offset / affix；事件：change（detail = { key }）。

常见问题

滚动到页顶（全未达线）时不高亮——antd 缺省语义。

子元素声明（静态路径）

<x-anchor-item> 由 precompile 变换折叠为 items JSON 落 data-items 通道 （宿主替换为真 nav）；href 显式声明原样生效。

offset 判定线（吸顶导航高度补偿）

锚顶越过「offset 线」即视为当前区块——页面顶部有固定吸顶条时用 offset 抵消其高度。
