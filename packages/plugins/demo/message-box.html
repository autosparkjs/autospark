autospark.message-box

确认询问对话（feedback 分类）——x-dialog 的确认语义组合壳（弹层机制全组合消费 x-dialog 指令，勿自建弹层）：type 图标映射 + 标题/内容 + 确认/取消双钮（组合消费 autospark.button）。确认/取消点击广播 confirm/cancel 事件（detail 空）并走请求关闭链 （visible 自动回写）。i18n 内置文案：confirmText/cancelText 缺省走词典 message-box.confirm/cancel 键（无 i18n 回退「确定/取消」）。

基础（danger 询问）

danger 询问的确认钮自动联动 danger 语义色（confirmType 缺省按 type 联动）；showCancel: false 关闭取消钮。

四档 type + 内容插槽

info / success / warning / danger 四档图标映射（alert 同款）；默认插槽可换富内容。

事件消费（confirm / cancel）

（尚无动作——点上方按钮并在弹层中选择）

事件物理边界（与 overlay:close 同款）：弹层 DOM 渲染在 body 容器内、不在 engine 宿主树内—— 消费用 document.addEventListener("confirm" | "cancel", ...)（模板里 @confirm 收不到）。
