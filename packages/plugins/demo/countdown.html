autospark.countdown

倒计时：time（毫秒时长，变化即重启新一轮）+ format token 模板（{d}{h}{m}{s}， 缺省 "{h}:{m}:{s}"）。计时引擎 = 递归 setTimeout + 绝对 deadline 真值（节流免疫 ——visibilitychange 回页补触发）。归零一次性派发 finish（detail 空）。样式复用 statistic 数值排版语言（tabular-nums）。语域与边界见 ADR-0031。

基础（缺省 format：时:分:秒）

秒杀场次 90 秒（time=90000）

{{ done ? '已归零（@finish 触发）' : '短倒计时 5 秒（finish 事件演示）' }}

format 变体（token 模板）

含 {d}：{h} 为日内余时（1 天 10:20:30 起）

不含 {d}：{h} 为总小时（可超 24）

重启（time 变化即新一轮——验证码 60s 重发）
