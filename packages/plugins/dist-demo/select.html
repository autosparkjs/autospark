autospark.select

下拉选择器（弹层交互自绘，ADR-0022）：触发器 = Field 盒饰形态（input 同款 chrome），下拉面板复用 x-popover 指令机制呈现（点击切换 / 面板外点击 / ESC 关闭机制继承）；值通道走 x-model 兼容协议（宿主 x-model 直写）+ 内嵌 hidden 载体原生直提交。键盘：上下键移动高亮 / Enter 确认 / ESC 关。

跨插件依赖：面板呈现须同时加载 autospark.overlay.js（x-popover 指令）； 长列表虚拟化另需 autospark.virtual.js（渐进增强）。

基础用法（x-model 双向 + 选中联动）

当前值：{{ v1 || '（空）' }}（options 经状态引用注入）

clearable / 禁用选项 / filterable

「广州」为禁用选项（淡化不可选）；过滤框内上下键 + Enter 同触发器键盘导航。

change 事件消费（detail = { value }）

最近选择：{{ picked || '（未操作）' }}；name 透传 hidden 载体（原生直提交）。

loading 加载态 / virtual 长列表（1000 项）

尺寸档位（主题通道 data-size）

档位属性挂在任意祖先容器即整片生效（面板字号与行高随档联动）。

状态色与禁用（status / disabled / readonly）

禁用不可开面板；只读可开面板浏览但选项不可选。
