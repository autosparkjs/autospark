autospark.tabs

页签：items（{ key, label, icon?, disabled? }[]，状态引用）或 <x-tab> 子元素 声明两形态；受控 value（el.value 桥 + change detail={value}）；variant 三形态 （line / card / segmented 分段控制器）；键盘左右移焦（tablist 语义）；面板区为 默认插槽（x-show / x-if.keepalive 切换）。

基础用法（items 状态引用 + 面板区 + change 回写）

面板 A：x-show 切换（DOM 保留，输入态不丢）。

面板 B：同一默认插槽内以消费者状态切换。

面板 C：x-if.keepalive 保活形态（离开时摘 DOM 但状态保留）。

x-model="view" 双向绑定激活项；面板 x-show / x-if.keepalive 绑同一状态。{{ log }}

子元素声明（静态页签头）+ 受控 value

受控形态：外层 @change 回写 view2；禁用项不可点击不可聚焦。

segmented 形态（分段控制器）

分段控制器（button-group 选中模式视觉近亲）：纯切换器用法，无面板区。

card 形态

键盘导航（tablist 语义）

聚焦任一页签后按 ← / → 环形移焦并自动激活，Home / End 首末直达（焦点漫游 tabindex：激活项 0、其余 -1）。
