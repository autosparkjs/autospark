autospark.watermark

水印（组件库 P4 other 件，ADR-0030）：容器形态（缺省，absolute 覆盖插槽内容） 或全页形态（full-page，层挂 body fixed 铺满）；canvas 离屏绘制旋转 文本单元 → data URL 平铺。内容保护（pointer-events 拦截）与防删除监听按简不做。

容器水印 + 多行 + 自定义样式

多行文案（content 状态引用注入 string[]）+ rotate/fontSize/gap/color 自定义。

声明形态：裸 content JSON 数组字符串（data-content 标量通道）。

全页水印（开关）

元素名写法 <x-watermark content="文案">；数组面 （content/gap 的 JSON 字符串）自动分流 data-* 标量通道（字面量数组 props 死环规避）。
