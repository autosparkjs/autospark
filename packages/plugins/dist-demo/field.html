autospark.field

表单域骨架（ADR-0020）：form 域家族的继承基座，也可直接实例化——默认出口装任意 控件内容即得骨架能力（状态色通道 / 焦点态 / disabled·readonly 同步 / .asc-field-box 盒饰选配类）。三出口：default（控件位）+ prefix / suffix 具名装饰出口（轻装饰 props 之外的重装饰层，ADR-0020 2026-11-14 修订）。

基础用法（直接实例化：默认出口装原生控件 + 盒饰类）

当前值：{{ price || '（空）' }} —— 宿主挂 asc-field-box 选配类得盒饰，内层控件标 data-autospark-control 接管禁用/焦点。

状态色通道（status → 边框/焦点环）

status 染 --asc-field-tone 中转变量：未聚焦即染边框，聚焦补同色光晕；error 态自动同步控件 aria-invalid。

disabled / readonly（同步原生控件 + 宿主反射）

三插槽（prefix / suffix 具名装饰出口）

插槽内容默认次要色、间距 0.4em；点击装饰转发焦点到控件——放交互件须自标 data-autospark-action（下一组演示）。

插槽内交互件（data-autospark-action 自理焦点）

未标记元素点击后焦点落控件；标记 data-autospark-action 的按钮点击不转发焦点（自理）。

尺寸档位（主题通道 data-size）

字号/字体族/内距/圆角经 --auto-* 主题变量全跟随（三级回退链，无 theme 环境吃兜底字面值）。
