autospark.steps

步骤条：items（{ title, description?, icon? }[]，状态引用）或 <x-step> 子元素 声明双形态；受控 current（el.value 桥 + clickable 点击切换 change detail={current}）；status 三态（process / finish / error 当前步异常）；direction 双排向；已完成步打勾 + 连接线进度染色。

基础用法（clickable 点击切换 + 受控回写）

先行步自动打勾、连接线随完成染色；点击步切换（current 索引 0 起）。

status 三态

process 进行中（实底序号）/ error 当前步异常（danger 叉号）/ finish 收尾（当前步也打勾）。

direction 纵排 + icon 自定义图标
