autospark.image-viewer

全屏图片查看器（display 分类）——自建 fixed 全屏层（不组合 x-dialog： 全屏暗色遮罩语境的查看器非居中对话框，自实现 ESC / 遮罩点击零跨插件依赖）： images / visible（受控显隐）/ index（受控当前图）+ 缩放/旋转/重置工具栏 + 键盘 （左右切换、ESC 关、±缩放）+ 前后翻页钮与计数器。全屏层为恒暗色设计 （不随主题明暗切换）。

与 image 组件联动（点击缩略图打开）

联动配方：缩略图 @click 写入 viewer.idx / viewer.open； 查看器的 change / close 事件经包裹层回写状态（受控闭环）。

受控打开（编程式）

键盘：← / → 切换、ESC 请求关闭、+ / - 缩放； 工具栏：放大 / 缩小 / 左旋 / 右旋 / 重置（1:1）/ 关闭；遮罩点击同样请求关闭。
