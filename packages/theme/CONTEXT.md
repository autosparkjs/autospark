# AutoSpark Theme（@autospark/theme）

CSS 变量驱动的运行时主题库：从单个主题色派生出整套界面变量（基础值 → 派生别名 → 组件类），支持暗色、多彩模式与全局 / 局部作用域。

## Language

### 颜色

**语义色（semantic color）**：
操作结果的语言：primary（品牌/主操作）、success、warning、danger、info 五色。值是**梯度种子**——生成同系 10 阶标尺（`--x-color-{name}-0..9`，0 浅 9 深），light 直引种子、暗色提亮引用浅档（ADR-0002）。
_Avoid_: 固定色值、覆盖色（旧机制词汇，语义色已非静态 hex）

### 显示模式

**独立样式域（data-* 手动通道）**：
模式维度（`data-light` / `data-dark`）与色彩维度（`data-colorized` / `data-uncolored`）构成的四属性手动通道——任意元素裸挂属性即可独立启用对应样式域，维度可自由组合（模式切换会把色彩重置为灰，同元素组合两维度才生效；色彩开关保留语境模式）。与作用域元素上的 `dark` / `colorized`（JS setter 通道）长期并存。根域裸属性追加；作用域收敛为「自身+后代」两式（跨作用域裸命中会错拿别的作用域的字面量梯度）。实现基础是模式块声明的 `--x-plain-*`（灰色方向）/ `--x-tinted-*`（多彩映射）别名层。
_Avoid_: 手动通道（旧称，已扩展为四属性）、data-theme=dark

**暗色（dark）**：
显示模式维度之一——前景/背景明度标尺互换、主题色梯度方向反转的深色呈现。两条启用通道并存：作用域元素上的 `dark` 属性（随作用域开关写入）与独立样式域的 `data-dark` 属性（元素单独启用）；可与多彩叠加（叠加态要求属性落在同一元素，经别名层自动取暗多彩映射）。
_Avoid_: 黑色主题、data-theme=dark（后者是主题色预设，属主题色维度而非显示模式维度）

**亮色（light）**：
显示模式维度之一——灰色方向的完整亮域（含 `color-scheme: light`，原生控件一并回亮），是无属性时的默认态。`data-light` 用于暗语境中单独切回亮元素；与 JS setter 通道不同（setter 只有 dark 开关，无 light）。
_Avoid_: 无亮色通道（旧认知）

**多彩（colorized）**：
与暗色对等的显示模式维度——灰阶幕布换为主题色浸染的色阶，可与暗色叠加。两条启用通道并存：作用域元素上的 `colorized` 属性与独立样式域的 `data-colorized` 属性。映射由语境模式块声明（亮 `bgcolor-i=theme-i`、暗 `bgcolor-1=theme-0 混黑 30%`），故暗语境中的多彩元素自动取暗映射。
_Avoid_: 彩色模式、染色、仅作用域可启用（旧认知）

**无彩（uncolored）**：
色彩维度的另一端——色彩两键回灰、模式随语境（`data-uncolored`）。灰的方向由最近的模式块决定：暗语境回暗灰、亮语境回亮灰。也是「暗语境中要多彩、但某元素要退灰」的降级手段。
_Avoid_: 灰度模式（整域灰度滤镜，非本机制）、反染色

### 输入控件

**输入控件（auto-input）**：
表单输入的统一外观入口。单一类名承载两种形态，形态由宿主标签决定，使用者无需记住第二个类名。
_Avoid_: input-wrapper、输入框包装器

**元素形态**：
输入控件直接标注在 input / select / textarea 等表单元素上的形态，承载完整输入外观；checkbox / radio / range 的定制只存在于这一形态。
_Avoid_: 裸输入、直接用法

**容器形态**:
输入控件标注在 div 等布局元素上的形态，用于组合复杂输入（前后缀、字段标签、选择类组合）；内部表单元素的外观由容器统一承载。
_Avoid_: wrapper、包裹器

**操作件（auto-input-action）**：
容器形态内的前后缀操作元素（按钮、图标），位置由 DOM 顺序决定。
_Avoid_: addon、前后缀、附加物

**字段标签（容器内 label）**：
容器形态内的 label 元素：与选择控件组合时表达选项并联动状态，与文本输入组合时表达字段名。与操作件的分工：字段标签回答「这是什么」，操作件回答「能做什么」。
_Avoid_: 行内标签、addon 文本

### 持久化

**样式快照（styles snapshot）**：
全部已连接主题作用域生成的 CSS 合成的单一字符串，持久化于 localStorage；回访时由恢复片段于首帧前回插，运行时启动重算重写实现自愈——过期快照的最坏结果与无持久化现状等价，故不设版本机制。
_Avoid_: 版本化快照、JSON 信封、无指纹静态层（不可校验、与运行时双真值源竞争；带指纹的构建期产物见「静态主题包」，ADR-0004）

**静态主题包（static theme package）**：
构建期由 `scripts/generate-theme.ts` 生成的单份全量 CSS（基量 + 主题标尺亮/暗块 + 语义色），与运行时注入同源（同一个不 connect 的 root ThemeScope.toStyles()，原名 generate()，ADR-0006 归并更名），文件头部带机器可读指纹（`--x-theme-static`，v2 共 15 字段：schema|生效hex|gap|cap|五语义种子|六维度默认）。宿主在 head 静态引入即可零 JS 正确首帧；运行时 root 作用域水合后比对指纹前 9 个颜色字段，完全一致才跳过三块注入，指纹存在但不一致则告警并回退动态注入。只服务 root 作用域；局部作用域、运行时任意换色仍走注入。浏览器端 `download()` 是同源导出通道：root 作用域产物经同一组装函数（assembleStaticThemeCss，ADR-0006）与 CLI 产物逐字节一致，下载时刻的维度状态一并烘焙。
_Avoid_: 无指纹静态 CSS、按名裸跳注入、静态化局部作用域、历史静态标尺文件（src/themes/*.less 旧体系，方向不统一，deprecated）

**维度烘焙（baked defaults）**：
静态主题包的可选形态扩展（ADR-0005）：dark/colorized/size/spacing/shadow/radius 六个纯运行时维度经「守卫块」纯追加在 toStyles() 输出之后——`:root:not([data-X])` 形选择器只在属性缺席的零 JS 首帧窗口命中，使首帧即呈烘焙形态；属性一经物化守卫失效、标准覆盖块以同值接管（幂等）。指纹尾部 6 个维度字段仅供首访（无水合参数）采纳为初始参数并随 connect 自然落盘，不参与失配判定（用户选择恒优先）。烘焙维度下「无属性」语义即烘焙值，回退库默认须显式写 `data-light` / `data-uncolored` / `data-size="medium"` 等。
_Avoid_: 基块替换（与运行时生成分叉）、维度字段参与指纹匹配（回访告警噪音）、编译期默认（烘焙值是包级首访默认，非编译常量）

**参数持久化（scope params）**：
每个主题作用域的用户可感参数（主题色/暗色/多彩/四尺寸）按作用域独立持久化；语义色与调色板参数属宿主级定制，不入快照。作用域启动先水合参数再注入，避免「恢复主题→默认主题→恢复主题」的二次闪烁。
_Avoid_: 全局单份参数、语义色持久化

**恢复片段（restore snippet）**：
宿主粘贴在 head 的阻塞内联脚本：读样式快照插入 `autospark-theme-restore` 标签，先于首帧还原用户主题；运行时 root 作用域接管后移除该标签。与静态主题包共存时必须位于静态 `<link>` 之后（用户最近选择优先）。
_Avoid_: restore.js 外链、库自动注入
