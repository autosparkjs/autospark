# AutoSpark Theme（@autospark/theme）

CSS 变量驱动的运行时主题库：从单个主题色派生出整套界面变量（基础值 → 派生别名 → 组件类），支持暗色、多彩模式与全局 / 局部作用域。

## Language

### 颜色

**语义色（semantic color）**：
操作结果的语言：primary（品牌/主操作）、success、warning、danger、info 五色。值是**梯度种子**——生成同系 10 阶标尺（`--x-color-{name}-0..9`，0 浅 9 深），light 直引种子、暗色提亮引用浅档（ADR-0002）。
_Avoid_: 固定色值、覆盖色（旧机制词汇，语义色已非静态 hex）

### 显示模式

**暗色（dark）**：
显示模式——前景/背景明度标尺互换、主题色梯度方向反转的深色呈现，以宿主元素上的 `dark` 属性标注；可与多彩（colorized）叠加。
_Avoid_: 黑色主题、data-theme=dark（后者是主题色预设，属主题色维度而非显示模式维度）

### 输入控件

**输入控件（auto-input）**：
表单输入的统一外观入口。单一类名承载两种形态，形态由宿主标签决定，使用者无需记住第二个类名。
_Avoid_: input-wrapper、输入框包装器

**元素形态**：
输入控件直接标注在 input / select / textarea 等表单元素上的形态，承载完整输入外观；checkbox / radio / range 的定制只存在于这一形态。
_Avoid_: 裸输入、直接用法

**容器形态**:
输入控件标注在 div 等布局元素上的形态，用于组合复杂输入（前后缀、字段标签、选择类组合）；内部表单元素的外观由容器统一承载。
_Avoid_: wrapper、包裹器

**操作件（auto-input-action）**：
容器形态内的前后缀操作元素（按钮、图标），位置由 DOM 顺序决定。
_Avoid_: addon、前后缀、附加物

**字段标签（容器内 label）**：
容器形态内的 label 元素：与选择控件组合时表达选项并联动状态，与文本输入组合时表达字段名。与操作件的分工：字段标签回答「这是什么」，操作件回答「能做什么」。
_Avoid_: 行内标签、addon 文本

### 持久化

**样式快照（styles snapshot）**：
全部已连接主题作用域生成的 CSS 合成的单一字符串，持久化于 localStorage；回访时由恢复片段于首帧前回插，运行时启动重算重写实现自愈——过期快照的最坏结果与无持久化现状等价，故不设版本机制。
_Avoid_: 版本化快照、JSON 信封、静态主题层

**参数持久化（scope params）**：
每个主题作用域的用户可感参数（主题色/暗色/多彩/四尺寸）按作用域独立持久化；语义色与调色板参数属宿主级定制，不入快照。作用域启动先水合参数再注入，避免「恢复主题→默认主题→恢复主题」的二次闪烁。
_Avoid_: 全局单份参数、语义色持久化

**恢复片段（restore snippet）**：
宿主粘贴在 head 的阻塞内联脚本：读样式快照插入 `autospark-theme-restore` 标签，先于首帧还原用户主题；运行时 root 作用域接管后移除该标签。
_Avoid_: restore.js 外链、库自动注入
