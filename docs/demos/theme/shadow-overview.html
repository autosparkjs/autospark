特性说明：阴影（Shadow）

阴影表达层级：浮起的卡片、弹层、下拉面板靠它拉开与背景的距离。 基础量 --x-shadow-* 六档，档位开关 data-shadow， 派生量 --auto-shadow 供组件消费。

  • 六档：none / x-small / small / medium（默认）/ large / x-large
  • 暗色换配方：深底上中灰阴影不可见，暗块把 --x-shadow-* 整体替换为黑色系高不透明度
  • 局部换档：容器加 data-shadow="档位"
ThemePro.shadow = "large"    // 全局阴影档
box-shadow: var(--auto-shadow);
层级场景：浮起面板与弹层
浮起面板：box-shadow: var(--auto-shadow)
面板内容
仅描边（无阴影）：border: var(--auto-border)
面板内容
卡片默认靠阴影浮起（加 border 类才显示边框）
.auto-card 的层级由 --auto-shadow 决定，随面板档位联动。

暗色下面板轮廓容易发虚（约 1.5:1），因此暗色同时提亮了边框色并换上暗阴影配方—— 「描边 + 阴影」双信号表达层级。
