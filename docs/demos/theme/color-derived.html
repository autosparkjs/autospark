特性说明：派生颜色（--auto-*）

派生层按用途命名（文字 / 背景 / 边框 / 交互态 / 面板 / 表单），值引用基础调色板。 组件只消费这一层，于是主题色、模式、色彩、尺寸四类开关全自动联动。

  • 文字三档：--auto-color → --auto-secondary-color → --auto-third-color
  • 背景四层：--auto-workspace-bgcolor → --auto-bgcolor → --auto-secondary-bgcolor → --auto-third-bgcolor
  • 交互四态：--auto-hover-* / --auto-active-* / --auto-selected-* / --auto-disable-*（各含 -color / -bgcolor / -border）
  • 速写：--auto-border = 1px solid {边框色}，一条声明即得完整边框
.my-panel { background: var(--auto-bgcolor); border: var(--auto-border); box-shadow: var(--auto-shadow); }
文字三档：同文同底，仅档位不同
主要文字 --auto-color
道可道，非常道；名可名，非常名。
→ var(--x-color-1)
次要文字 --auto-secondary-color
道可道，非常道；名可名，非常名。
→ color-mix(主文字, transparent 25%)
辅助文字 --auto-third-color
道可道，非常道；名可名，非常名。
→ color-mix(主文字, transparent 45%)
背景四层：从工作区到内嵌块
--auto-workspace-bgcolor（工作区 / 应用底）
--auto-bgcolor（面板 / 卡片）
--auto-secondary-bgcolor（次级面板，原料 45% 不透明）
--auto-third-bgcolor（内嵌块，同一原料 75% 不透明）

语义背景以透明度区分层次：面板是实色容器，次级与内嵌共用同一原料 （--x-bgcolor-2）的两档不透明度——四层阶梯在亮 / 暗 / 多彩下都保持单调。

hover / selected 取主题色（--auto-theme-color），active 取更深一档 （theme-8），disable 由文字色混灰而来；暗色下这四态的参数被 darkDerivedVars 整体重算，组件层保持模式无关。

边框与表单：--auto-border* / --auto-input-*
默认 --auto-border
hover --auto-hover-border
selected --auto-selected-border
disable --auto-disable-border
¥
表单外观全部由 --auto-input-{font,border,bgcolor,placeholder,padding,radius,height} 转发通用派生值，自定义控件逐项引用即可与 .auto-input 观感一致。
面板与排版
面板头部：font(--auto-panel-header) / bg(--auto-panel-header-bgcolor)
面板主体背景 --auto-panel-bgcolor
字体速写 --auto-font，标题字体 --auto-title-font
辅助文字 --auto-third-color

面板类派生值（--auto-panel-header* / --auto-panel-bgcolor） 与排版类（--auto-font / --auto-title-font）分别服务于「容器」与「文字」两类组件。
