四份调色板（左列为默认亮语境，右列为 data-dark 语境）
亮语境（无属性）
主题调色板 --x-color-theme-0..9（0 浅 → 9 深）
灰阶方向 --x-plain-color-0..9（0 最深文字）
灰阶背景方向 --x-plain-bgcolor-0..9
暗语境（data-dark）
同一族变量：主题梯度反转（0 深 → 9 浅），灰方向也随之反转
灰阶方向 --x-plain-color-0..9（暗块声明的另一份方向）
灰阶背景方向 --x-plain-bgcolor-0..9

固定的灰度原料是 --x-color-gray-0..9（静态层常量，与主题无关）； 主题与灰度的「方向」由亮 / 暗两个模式块各自声明成 --x-plain-*（灰方向）与 --x-tinted-*（多彩映射）别名，基础调色板只负责引用其中一份。

「反转」不是把色值倒序，而是方向语义的互换：亮色下背景取浅档、文字取深档； 暗色下明度关系反过来，同一套映射（bgcolor-i = theme-i）才能继续成立。
