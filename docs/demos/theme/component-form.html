特性说明：组件变量 · 表单（Form / Input）

表单外观由 --auto-input-* 一组变量统一承载：字体 / 边框 / 背景 / 占位符 / 内距 / 圆角 / 高度。它们全部转发通用派生值，因此主题色、模式、尺寸任一维变化都自动跟随。

--auto-input-bgcolor--auto-bgcolor（暗色改指工作区色，凹陷流派）
--auto-input-placeholder主文字色 40% 不透明
--auto-input-padding / -radius--auto-padding / --auto-border-radius
--auto-input-height--x-input-height-*（当前未定义，解析为空——高度实际由行高决定）
元素形态：类名直接标注在表单元素上

checkbox / radio / range 的定制只存在于此形态 （元素形态与容器形态共用同一套 Less mixin，源码只有一份）。
