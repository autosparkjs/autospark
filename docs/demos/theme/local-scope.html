特性说明：局部主题（ThemeScope）

作用域是「一套完整主题参数 + 一个边界」：root 作用域覆盖整篇文档， addScope() 创建的作用域覆盖指定子树，两者参数、注入与持久化链路完全同构。 

const scope = ThemePro.addScope({
    id: "preview",                    // 作用域标识（必填）
    elements: ["#preview"],           // 自动给命中元素挂 data-theme-scope="preview"
    themeColor: "magenta",            // 本子树自己的主题色
});
scope.dark = true;                    // 模式 / 尺寸经 setter 立即写属性
scope.radius = "small";
  • 每个作用域有自己的主题色、模式、尺寸——互不影响
  • 作用域内仍可用 data-* 做元素级微调（命中被收敛在本作用域子树内）
  • WebComponent / shadow DOM 场景传 docRoot 与 cssSelector: [":host"]

按钮走的是 scope.dark = … 这类 setter：更新 options → 同步 DOM 属性（dark / data-radius 等）→ 持久化参数。构造选项里的模式与尺寸不会立即生效 （属性同步只发生在 setter 与水合路径），需要立刻见效时构造后显式赋值一次。

WebComponent / shadow DOM
const scope = new ThemeScope({
    id: "wc",
    docRoot: this.shadowRoot,      // 注入与查询都在影子根内进行
    cssSelector: [":host"],        // 影子根内用 :host
    themeColor: "green",
});

docRoot 同时决定注入位置与查询范围；isConnected() 也在 docRoot.ownerDocument 中查找样式标签。本页右侧控制面板自身就是 WebComponent， 它的样式经 Shadow DOM 自包含、配色则从宿主继承 --auto-* 变量。
