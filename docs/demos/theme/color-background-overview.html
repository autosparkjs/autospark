特性说明：背景色（Background）

背景由基础调色板的背景梯度 --x-bgcolor-0..9 提供原料， 派生层再按用途切成四层：工作区 / 面板 / 次级 / 内嵌。层次不靠「不同颜色」， 而靠档位 + 不透明度的单调阶梯。

派生变量 配方 用途
--auto-workspace-bgcolor--x-bgcolor-1应用底 / 工作区
--auto-bgcolor--x-bgcolor-0面板 / 卡片 / 弹层
--auto-secondary-bgcolorbgcolor-2 55% 透明次级面板 / 分区
--auto-third-bgcolorbgcolor-2 25% 透明内嵌块 / 代码块
--auto-panel-bgcolor--auto-bgcolor面板 / Drawer
--auto-panel-header-bgcolor--auto-secondary-bgcolor标题栏 / 标签页头
