标题字体与排版速写
标题字体 var(--auto-title-font)
正文字体 var(--auto-font)
--auto-font-family: var(--auto-font-family)
字距 --auto-letter-spacing / 行高 --auto-line-height 一并由 --auto-font 聚合。
元素域：data-size 局部换档（三卡并排）
data-size="x-small"
道可道，非常道；名可名，非常名。
data-size="medium"（= 默认态）
道可道，非常道；名可名，非常名。
data-size="x-large"
道可道，非常道；名可名，非常名。

--auto-font 在每个 [data-size=x] 档位块内都重新声明一遍， 所以局部 data-size 容器里的 font: var(--auto-font) 会同步换档； data-size 属规模维度，与模式维度（data-dark）、 色彩维度（data-colorized）分属不同域、可同元素叠加，两域各自生效。
