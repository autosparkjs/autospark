特性说明：背景色（Background）

背景由基础调色板的背景梯度 --x-bgcolor-0..9 提供原料， 派生层再按用途切成四层：工作区 / 面板 / 次级 / 内嵌。层次不靠「不同颜色」， 而靠档位 + 不透明度的单调阶梯。

派生变量 配方 用途
--auto-workspace-bgcolor--x-bgcolor-1应用底 / 工作区
--auto-bgcolor--x-bgcolor-0面板 / 卡片 / 弹层
--auto-secondary-bgcolorbgcolor-2 55% 透明次级面板 / 分区
--auto-third-bgcolorbgcolor-2 25% 透明内嵌块 / 代码块
--auto-panel-bgcolor--auto-bgcolor面板 / Drawer
--auto-panel-header-bgcolor--auto-secondary-bgcolor标题栏 / 标签页头
四层剖面：工作区 → 面板 → 次级 → 内嵌
--auto-workspace-bgcolor（工作区）
--auto-bgcolor（面板）
--auto-secondary-bgcolor（次级）
--auto-third-bgcolor（内嵌）

右侧面板切暗色：暗色的背景映射前景与背景分离——bgcolor-0（面板）取 gray-8、bgcolor-1（工作区）取最沉的 gray-9， 于是面板浮起在工作区之上，四层阶梯依旧单调。

背景梯度 --x-bgcolor-0..9（面板 / 工作区 / 扩展档）
亮语境
0 最浅（面板）→ 9 最深；1 为工作区（比面板略深）
暗语境（data-dark）
0 = gray-8（面板，浮起）→ 1 = gray-9（工作区，最沉）→ 2..9 递亮
亮多彩（data-colorized）
bgcolor-i = theme-i：整条幕布被主题色浸染
暗多彩（data-dark data-colorized）
bgcolor-1 = theme-0 混黑 30%（彩色梯度无更深档，压暗保色相）
透明度叠加：次级 / 内嵌为何不另取色
面板底（实色）
secondary = 同一原料 45% 不透明
third = 同一原料 75% 不透明

同一原料（bgcolor-2）用两档不透明度，在亮 / 暗 / 多彩下都落在可辨区间—— 好处是次级块叠在任意底色上都自然（不必为每种底色各配一个色值）。

背景色与组件：整页结构剖面
卡片头（--auto-panel-header-bgcolor）
卡片体（--auto-bgcolor）
内嵌块（--auto-secondary-bgcolor）

业务自定义容器时按「外层用 workspace、容器用 bgcolor、内嵌用 secondary / third」的顺序引用， 即可获得与内置组件一致的空间感；不要写死颜色——写死会让模式切换失效。
