特性说明：明暗主题（dark / light）

显示模式是独立维度：亮色是默认态，暗色经 dark 属性（JS 通道）或 data-dark 属性（元素域手动通道）启用。暗色下前景 / 背景明度标尺互换、 主题梯度方向反转，并附带一批暗色专属派生值与暗色阴影配方。 

AutoSparkThemeManager.dark = true              // 全局暗色（写 :root 的 dark 属性，参与持久化）
<div data-dark>…</div>           // 仅此元素进入暗色（元素域，不进持久化）
<div data-light>…</div>          // 暗语境中单独切回亮色（含 color-scheme: light）
  • 暗色 color-scheme: dark——滚动条等原生控件一并换暗；data-light 是对偶的完整亮域
  • 主题梯度反转：亮 theme-0 最浅，暗 theme-0 最深（同一套映射才继续成立）
  • 可读性有量化兜底：暗色各档按 WCAG 对比度校准（正文 ≥ 4.5:1、图形 ≥ 3:1）
