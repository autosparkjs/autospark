特性说明：组件变量 · 段落（Paragraph）

段落类变量服务于大段文本的阅读密度：行高与字距两档基础量， 经 --auto-line-height / --auto-letter-spacing 派生，并被 --auto-font 速写一并聚合。

  • 行高：文本行间垂直间距，值越大越松弛；字距：字符水平间距，中文排版通常保持默认
  • 两者都以 --x-spacing-medium 为基准计算——间距梯度是排版的底层标尺
  • 消费 --auto-* 的段落随档位联动；写死 --x-* 的段落不联动
p { font: var(--auto-font); line-height: var(--auto-line-height); letter-spacing: var(--auto-letter-spacing); }
