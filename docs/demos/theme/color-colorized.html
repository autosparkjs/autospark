特性说明：多彩模式（colorized）与无彩（uncolored）

色彩是与显示模式正交的第二个维度：灰阶幕布换为主题色浸染的色阶。 它与暗色一样有 JS 通道（colorized 属性）与元素域手动通道 （data-colorized / data-uncolored）。 

ThemePro.colorized = true                    // 全局多彩（写 :root 的 colorized 属性）
<div data-colorized>…</div>                 // 仅此元素多彩（模式随语境）
<div data-dark data-colorized>…</div>       // 叠加：暗色 + 多彩（须同一元素）
<div data-uncolored>…</div>                 // 色彩回灰、模式随语境（暗语境回暗灰）
  • 映射由语境模式块声明：亮 bgcolor-i = theme-i；暗 bgcolor-1 = theme-0 混黑 30%
  • 所以「暗语境中的多彩元素」自动取暗多彩映射，不必额外声明
  • 无彩是降级手段：既想留在暗语境、又想让某块回灰时用它

外层多彩：本段文字与输入框都被主题色浸染。
内层 data-uncolored：色彩回灰，模式随语境。

灰的方向由最近的模式块决定：外层切暗时，内层 data-uncolored 回的是暗灰—— 这是「暗语境中要多彩、但某元素要退灰」的标准降级手段。

叠加态与已知限制
data-dark + data-colorized 同元素：暗多彩（厚重暗底）
命中叠加块 [data-dark][data-colorized]，实际值改引用暗多彩映射。
暗卡内的 data-colorized 后代（不受支持）
外层 data-dark。
这个后代挂了 data-colorized，但跨元素组合不命中叠加块—— 它会取亮语境的多彩映射，看起来「没跟着暗」。要叠加请把两个属性放到同一元素。

非作用域元素上手工挂 dark / colorized（不带 data-）只命中叠加块、不命中普通暗色 / 多彩块—— 日常请统一用 data-* 手动通道，或经 scope.dark 这类 setter 写作用域元素。
