特性说明：持久化与回访零闪

主题 CSS 全部由运行时注入，因此回访用户首帧必然闪一次默认主题——除非把上次的产物提前还给他。 持久化做两件事：样式快照（全部作用域 CSS 合成一个字符串）与 参数持久化（每个作用域的用户可感参数）。

  • 本页 <head> 里就放着恢复片段：切换主题后刷新页面，首帧直接是上次的主题（零闪）
  • 快照 key {storageKey}-styles、参数 key {storageKey}-scope-{id}，默认前缀 autospark-theme
  • 运行时每次注入变化都会全量重写快照——库升级后旧快照会被新产物覆盖（自愈），因此不需要版本号
参数范围：只有用户可感的七个
{ "themeColor": "#722ed1", "dark": true, "colorized": false,
  "size": "medium", "radius": "small", "spacing": "medium", "shadow": "medium" }

语义色与调色板形态参数不入快照——它们属宿主级定制：若被写进本地， 宿主升级默认值后会被旧参数钉死。

行为矩阵
场景首帧稳定后
首次访问默认主题（FOUC，接受）应用参数后的主题
回访（片段 + 快照齐全）上次主题（零闪）重算重写，与首帧一致
回访（库升级改变了输出）旧主题新产物覆盖快照（自愈窗口）
回访（localStorage 不可用）默认主题应用当前参数（不落盘）
persistence: false 的作用域不参与快照照常注入渲染

所有 localStorage 读写都包在 try/catch 中：iOS 隐私模式等不可写环境静默降级为无持久化，功能不受影响（只是回访会闪）。
