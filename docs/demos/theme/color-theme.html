特性说明：主题色（Theme Color）

主题色是整套界面的唯一输入：给它一个色值，Material 风格色板扩散算法生成 10 阶梯度 --x-color-theme-0..9（亮语境 0 最浅 → 9 最深，暗语境反转）。

  • 取值：12 个预设名（blue / red / …）或任意可解析色值（hex / rgb() / 命名色）
  • "light" 表示关闭主题色：不注入标尺，界面退回纯灰阶
  • 常用档：theme-5 是中值（--auto-theme-color），浅底取 0-2，强调取 7-9
ThemePro.themeColor = "purple"   // 预设名
ThemePro.themeColor = "#7c3aed"  // 任意色值
ThemePro.themeColor = "light"    // 关闭主题色
主题梯度：右侧面板换主题色，本卡实时跟随

10 档全部由算法从种子色扩散而来（种子落在与它色差最小的基准色板档位上，其余档按该骨架的明度 / 彩度系数展开）。 拖动面板的「自定义颜色」可逐像素观察梯度重算。

主题色消费点：这些位置都读 --auto-theme-color
选中态（--auto-selected-*）
悬停我（--auto-hover-*）
档位引用（业务自定义层次时直接用标尺）：
background: var(--x-color-theme-1)
background: var(--x-color-theme-5)
background: var(--x-color-theme-8)
预设对照：同一份算法，不同种子（每格一个独立作用域）

每格是独立主题作用域（addScope({ themeColor: 预设名 })）， 所以能同屏对照多套梯度；面板里可切换全部 12 个预设。

任意色值：算法按输入色的亮度自适应

浅色种子（#a0d911）与深色种子（#2f54eb）得到的两条梯度都单调、可读—— 种子只决定色相与彩度位置，明暗节奏由基准色板骨架给出。
