特性说明：静态主题包与静态样式层

主题库的样式分三层，可独立使用也可叠加：

层 内容 产物 / 入口
静态样式层 reset、工具类、组件类、灰阶常量、图标、动画 dist/index.css（Less 编译）
运行时主题层 主题标尺、语义色、模式 / 色彩 / 尺寸变量、派生层 运行时注入 <style>
静态主题包 11 套写死的主题标尺（data-theme=blue 等） src/themes/*.less → dist/themes/*.css
  • 静态主题包不经运行时：给元素挂 data-theme="blue" 即得该套色阶
  • 本页引入的 /autospark/autospark-theme.css 正是静态样式层的全量编译产物（docs.less 聚合）
  • 运行时层与静态层叠加时，运行时注入的标尺特异性更高、按暗色规则反转，两者不冲突
静态主题包 vs 运行时预设
静态主题文件 运行时预设表
清单 11 套（含 yellow / dark，无 gold / geekblue / techblue） 12 套（blue / red / volcano / orange / lime / gold / green / cyan / geekblue / techblue / purple / magenta）
色阶来源 构建期写死的 hex 运行时按算法从种子派生
切换方式 改 data-theme 属性（或加载对应 CSS） AutoSparkThemeManager.themeColor = name
适用 完全不经运行时的消费者 需要运行时换肤的消费者
把运行时产物静态化：scope.toStyles() / download()
const css = AutoSparkThemeManager.root.toStyles();  // 作用域全量 CSS（基础变量 → 主题标尺 → 语义色）
AutoSparkThemeManager.root.download();            // 直接下载 .css —— root 产物即合规静态主题包（ADR-0006）

这条路径适合「要运行时主题的全部变量、但不想在页面里跑运行时」的构建期方案： 用 toStyles()（或 download()）在构建脚本里生成 CSS， 产物与运行时注入的内容同源；root 作用域的下载产物带指纹头、与 generate-theme CLI 产物逐字节一致，挂 <link> 即可被运行时指纹接管。
