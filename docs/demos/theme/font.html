特性说明：字体（Font）

字体要素是「一套五档基础量 + 一个档位开关 + 一组派生量」的标准结构： 基础量 --x-font-size-* / --x-font-weight-* 给绝对值， 档位开关 data-size 选档，派生量 --auto-font-* 供组件消费。

  • 分解别名：--auto-font-size / --auto-font-weight / --auto-font-family
  • 速写：font: var(--auto-font) = 字重 + 字号 / 行高 + 字体族
  • 标题排版：font: var(--auto-title-font)（在默认字体基础上加大字重与字号）
ThemePro.size = "large"     // 全局字号档（写 :root 的 data-size 属性）
<div data-size="x-small">  // 元素域局部换档

自动字体 vs 固定字体（面板切「尺寸」观察差异）
自动字体：消费 --auto-font，随全局档位联动
道可道，非常道；名可名，非常名。无名天地之始，有名万物之母。故常无欲，以观其妙；常有欲，以观其徼（jiào）。
固定字体：写死 --x-font-* medium，不随档位变化
道可道，非常道；名可名，非常名。无名天地之始，有名万物之母。故常无欲，以观其妙；常有欲，以观其徼（jiào）。

两者初始观感相同（全局默认 medium）；把面板「尺寸」切到 x-small 或 x-large：左侧整体缩放、右侧不动——这就是消费派生量与写死基础量的本质区别。

标题字体与排版速写
标题字体 var(--auto-title-font)
正文字体 var(--auto-font)
--auto-font-family: var(--auto-font-family)
字距 --auto-letter-spacing / 行高 --auto-line-height 一并由 --auto-font 聚合。
元素域：data-size 局部换档（三卡并排）
data-size="x-small"
道可道，非常道；名可名，非常名。
data-size="medium"（= 默认态）
道可道，非常道；名可名，非常名。
data-size="x-large"
道可道，非常道；名可名，非常名。

data-size 属规模维度，与模式维度（data-dark）、 色彩维度（data-colorized）分属不同域、可同元素叠加—— 下面右卡同时挂 data-dark 与 data-size，两域各自生效。

维度叠加：data-dark × data-size
data-dark + data-size="x-small"
暗色 + 最小字号：两域互不覆盖。
data-dark + data-size="x-large"
暗色 + 最大字号：两域互不覆盖。
