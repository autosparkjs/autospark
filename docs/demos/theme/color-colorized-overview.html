特性说明：多彩模式（colorized）与无彩（uncolored）

色彩是与显示模式正交的第二个维度：灰阶幕布换为主题色浸染的色阶。 它与暗色一样有 JS 通道（colorized 属性）与元素域手动通道 （data-colorized / data-uncolored）。 

ThemePro.colorized = true                    // 全局多彩（写 :root 的 colorized 属性）
<div data-colorized>…</div>                 // 仅此元素多彩（模式随语境）
<div data-dark data-colorized>…</div>       // 叠加：暗色 + 多彩（须同一元素）
<div data-uncolored>…</div>                 // 色彩回灰、模式随语境（暗语境回暗灰）
  • 映射由语境模式块声明：亮 bgcolor-i = theme-i；暗 bgcolor-1 = theme-0 混黑 30%
  • 所以「暗语境中的多彩元素」自动取暗多彩映射，不必额外声明
  • 无彩是降级手段：既想留在暗语境、又想让某块回灰时用它
