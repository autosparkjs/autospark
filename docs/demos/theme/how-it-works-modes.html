基础调色板 × 两个开关 = 四种颜色模式

四卡内容完全相同（只消费 --x-color-* / --x-bgcolor-* / --auto-*），仅容器上挂的 data-* 属性不同—— 右侧面板切换主题色，四卡同时跟随；切换暗色 / 多彩，只有未固定属性的卡跟随。

light（无属性）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
light + colorized（data-colorized）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
dark（data-dark）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
dark + colorized（data-dark data-colorized）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color

--x-color-* / --x-bgcolor-* 是「基础调色板」—— 真正随模式与色彩切换的一组变量，业务自定义样式最该引用它们； --x-color-gray-*（固定灰）与主题色梯度组合成这套基础调色板。
