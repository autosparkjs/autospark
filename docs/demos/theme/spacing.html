特性说明：间距（Spacing）

间距控制界面的稀疏度：基础量 --x-spacing-* 六档（含 none）， 档位开关 data-spacing，派生量 --auto-spacing / --auto-padding / --auto-margin 供组件消费。

  • 六档：none（0）/ x-small / small / medium（默认）/ large / x-large
  • 字号档 data-size 也会联动间距（sizeVars 同时给出字号与内距），data-spacing 用于单独调节稀疏度
  • 行高 / 字距以 --x-spacing-medium 为基准计算——间距梯度是排版的底层标尺
ThemePro.spacing = "small"     // 全局收紧
padding: var(--auto-padding);

六档实测值：0 / 0.4rem / 0.6rem / 0.8rem / 1.0rem / 1.2rem—— 档距约 0.2rem，肉眼可辨但不过分。

间距 × 字号：两个规模维度的分工
data-size="small"（字号 + 内距一起收）
字号随档位变小
data-spacing="x-small"（只收间距，字号不变）

data-size="large" + data-spacing="none"
大字号 + 零间距

data-size 是「整体缩放」（字号 / 字重 / 行高 / 字距 / 内距 / 阴影 / 图标一起换）， data-spacing 是「只调稀疏度」。要微调密度而不动排版时用后者。

间距作为排版基准：行高 / 字距
行高 small：--x-spacing-medium × 1.7。道可道，非常道；名可名，非常名。
行高 large + 字距 large：--x-spacing-medium × 2.1。道可道，非常道；名可名，非常名。

行高与字距都以 --x-spacing-medium 为基准计算，因此改间距梯度会同时影响段落排版的「呼吸感」。
