特性说明：字体（Font）

字体要素是「一套五档基础量 + 一个档位开关 + 一组派生量」的标准结构： 基础量 --x-font-size-* / --x-font-weight-* 给绝对值， 档位开关 data-size 选档，派生量 --auto-font-* 供组件消费。

  • 分解别名：--auto-font-size / --auto-font-weight / --auto-font-family
  • 速写：font: var(--auto-font) = 字重 + 字号 / 行高 + 字体族
  • 标题排版：font: var(--auto-title-font)（在默认字体基础上加大字重与字号）
AutoSparkThemeManager.size = "large"     // 全局字号档（写 :root 的 data-size 属性）
<div data-size="x-small">  // 元素域局部换档
维度叠加：data-dark × data-size
data-dark + data-size="x-small"
暗色 + 最小字号：两域互不覆盖。
data-dark + data-size="x-large"
暗色 + 最大字号：两域互不覆盖。
