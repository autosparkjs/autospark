特性说明：组件变量 · 面板（Panel / Card）

面板类变量把「容器」这件事拆成四件可复用的东西：背景层次、 边框、圆角、阴影； 标题栏再额外消费一组「头部」变量（字体 / 颜色 / 背景）。

变量用途
--auto-panel-bgcolor面板 / 区块 / Drawer 背景
--auto-panel-header-bgcolor标题栏 / 标签页头背景
--auto-panel-header / --auto-panel-header-color标题栏字体与文字色
--auto-border / --auto-border-radius / --auto-shadow容器外框三件套
--auto-padding容器内距
