特性说明：元素域（独立样式域）

除了「作用域」（ThemeScope，一套完整主题参数 + 边界）之外，还有一层更轻的机制： 任意元素裸挂 data-* 属性即可局部启用某个样式域，不需要建作用域、不进持久化。

维度属性效果
模式data-dark / data-light暗色 / 亮色（含 color-scheme）
色彩data-colorized / data-uncolored多彩 / 回灰（模式随语境）
规模data-size / data-radius / data-spacing / data-shadow字号体系 / 圆角 / 间距 / 阴影换档
  • 维度之间正交：可同元素叠加（data-dark data-size="x-small"）
  • 叠加要求属性落在同一元素：暗色 + 多彩跨元素组合不命中叠加块
  • 作用域内会收敛：局部作用域的 data-* 只命中本作用域子树，不跨域错拿梯度
模式与色彩：四种组合（点击按钮实时开关）
无属性 / data-light：亮色灰调
data-dark：暗色灰调
data-colorized：多彩（模式随语境）
data-dark + data-colorized 同元素：叠加态

组合语义：模式切换会把色彩重置为灰——两维度要同时生效必须同元素组合； 单独的色彩开关则保留语境模式（data-colorized 在暗语境取暗多彩映射）。

维度独立：暗内亮 / 彩内灰
暗卡中的亮元素（data-light）
外层暗色：本段取暗色变量。
内层 data-light：完整亮域，原生控件（滚动条等）一并回亮。
彩卡中的灰元素（data-uncolored）
外层多彩：本段被主题色浸染。
内层 data-uncolored：色彩回灰、模式随语境。
规模维度：字号 / 圆角 / 间距 / 阴影四档同时叠加
紧凑：x-small + 直角 + 无阴影
字号 / 内距 / 圆角 / 阴影四域同时收窄
宽松暗色：模式域 + 四个规模域叠加
模式域与规模域互不覆盖，各自生效

注意：规模档位块的选择器是「作用域限定式 + 裸属性式」并列，所以裸 data-* 尺寸属性在任意元素上都生效—— 尺寸值与主题色 / 模式无关，全局命中不会产生冲突。

作用域收敛：data-* 不跨作用域错拿梯度
作用域外的宿主（全局蓝梯度）
本卡不属于任何局部作用域。
裸 data-dark：命中根域裸暗色块（蓝梯度反转）。
局部作用域 esGuard（青色 cyan 梯度）
本卡是 cyan 作用域：字面量梯度与根域不同。
作用域内的 data-dark：命中 S [data-dark]，取青色作用域自己的暗色块。
