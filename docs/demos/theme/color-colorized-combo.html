叠加态与已知限制
data-dark + data-colorized 同元素：暗多彩（厚重暗底）
命中叠加块 [data-dark][data-colorized]，实际值改引用暗多彩映射。
暗卡内的 data-colorized 后代（不受支持）
外层 data-dark。
这个后代挂了 data-colorized，但跨元素组合不命中叠加块—— 它会取亮语境的多彩映射，看起来「没跟着暗」。要叠加请把两个属性放到同一元素。

非作用域元素上手工挂 dark / colorized（不带 data-）只命中叠加块、不命中普通暗色 / 多彩块—— 日常请统一用 data-* 手动通道，或经 scope.dark 这类 setter 写作用域元素。
