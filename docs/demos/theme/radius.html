特性说明：圆角（Border Radius）

圆角为面板、按钮、输入框提供统一的圆角语言：基础量 --x-border-radius-* 六档 （另有 pill / circle 两个特殊值），档位开关 data-radius， 派生量 --auto-border-radius 供组件消费。

  • 六档：none（直角）/ x-small / small / medium（默认）/ large / x-large
  • 特殊值：pill（胶囊 9999px）、circle（正圆 50%，需正方形容器）——仅基础量，不参与档位切换
  • 局部换档：任意容器加 data-radius="档位" 即可，无需改全局
ThemePro.radius = "large"                       // 全局
<div data-radius="none">…</div>              // 元素域局部

圆角相同（medium）而尺寸不同：小元素视觉接近直角、大容器更显圆润—— 小控件宜选 x-small / small，大面积容器宜选 large / x-large。
