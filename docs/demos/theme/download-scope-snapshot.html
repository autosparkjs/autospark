局部作用域的产物是「快照」，不是静态包

静态层契约只服务 root 作用域（ADR-0004）：局部作用域的下载产物选择器是该作用域自身的， 挂 <link> 后运行时不会对它做指纹接管——因此 download() 在非 root 作用域会 console.warn 一次，然后导出 toStyles() 快照。

  • 快照的合法用途：SSR 取数、调试导出、给「不跑运行时」的局部容器做样式交付
  • 要全局静态主题包，请用 AutoSparkThemeManager.root.download() 或 generate-theme CLI
