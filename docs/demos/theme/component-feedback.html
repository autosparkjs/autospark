特性说明：组件变量 · 交互反馈（Hover / Active / Selected / Disabled）

四态反馈各有独立的一组变量（-color / -bgcolor / -border）， 值由主题色与基础调色板派生，因此换主题色、切模式都自动跟随，组件层不必写任何条件分支。

态颜色来源底色配方
hover--auto-theme-color主题色 15% 透明叠加
active--x-color-theme-8（更深一档）主题色 15% 透明叠加
selected--auto-theme-color主题色 20% 透明叠加（暗色 18%，感知对称）
disable文字色混灰（暗色混灰比例更高）currentColor 20% 透明
