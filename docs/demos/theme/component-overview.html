特性说明：组件变量（Component Variables）

「组件变量」是派生层按组件类型重新分组后的视角：颜色与尺寸要素提供原料， 组件类（.auto-card / .auto-btn / .auto-input / .auto-alert）与业务自定义组件消费同一批 --auto-* 变量。

  • 段落：行高 / 字距 / 字体速写——--auto-line-height / --auto-letter-spacing / --auto-font
  • 面板：容器的背景 / 边框 / 圆角 / 阴影 / 标题栏——--auto-panel-* / --auto-border / --auto-shadow
  • 表单：输入控件单类双形态——--auto-input-*
  • 交互反馈：悬停 / 按下 / 选中 / 禁用——--auto-{hover,active,selected,disable}-*
