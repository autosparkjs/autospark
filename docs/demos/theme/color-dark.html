特性说明：明暗主题（dark / light）

显示模式是独立维度：亮色是默认态，暗色经 dark 属性（JS 通道）或 data-dark 属性（元素域手动通道）启用。暗色下前景 / 背景明度标尺互换、 主题梯度方向反转，并附带一批暗色专属派生值与暗色阴影配方。 

ThemePro.dark = true              // 全局暗色（写 :root 的 dark 属性，参与持久化）
<div data-dark>…</div>           // 仅此元素进入暗色（元素域，不进持久化）
<div data-light>…</div>          // 暗语境中单独切回亮色（含 color-scheme: light）
  • 暗色 color-scheme: dark——滚动条等原生控件一并换暗；data-light 是对偶的完整亮域
  • 主题梯度反转：亮 theme-0 最浅，暗 theme-0 最深（同一套映射才继续成立）
  • 可读性有量化兜底：暗色各档按 WCAG 对比度校准（正文 ≥ 4.5:1、图形 ≥ 3:1）
同一段界面在两种模式下的观感（右侧面板切「暗色模式」）
亮色（无属性）
面板头部
主要文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
提示 --auto-info-color
暗色（data-dark 固定在本卡，与全局无关）
面板头部
主要文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
提示 --auto-info-color

左侧无属性（跟随全局，面板切暗色它会一起变暗）；右侧固定 data-dark—— 这就是「元素域」：局部暗色不需要建作用域。

梯度方向反转：同一族变量、两个方向
暗语境内的三条同名梯度（继承的是解析后的值 → 方向已反转）
亮语境的同一族变量（对照）
元素域开关：data-dark 的独立与嵌套
本卡独立启用 / 关闭暗色，页面其余部分不受影响。
暗卡内嵌亮卡（data-light 的用途）
外层暗色：本段文字与输入框取暗色变量。
内层 data-light：完整亮域，连 color-scheme 一并回亮。

注意：data-dark 与 data-colorized 要落在同一元素才命中叠加块—— 跨元素组合（暗父 + 彩子）不会叠加，此时可用 data-uncolored 让子元素回灰但保留模式。

暗色专属派生值：变量层吸收模式差异
变量 亮色 暗色
--auto-theme-color theme-5 theme-6（梯度反转后需提档保对比）
--auto-border-color --x-color-6 --x-color-8（面板轮廓提亮）
--auto-input-bgcolor 面板色 --x-bgcolor-1（工作区色，凹陷流派）
--auto-disable-color 文字色混灰 50% 混灰 80%（深底保底可辨）
--x-shadow-* 中灰低不透明 黑色系高不透明（深底上灰阴影不可见）

组件层永远保持模式无关——它只写 var(--auto-*)，模式差异全部在变量层完成。 校准脚本 bun scripts/check-dark-contrast.ts 与变量同源，改完可直接跑数值回归。
