root 下载产物的解剖：与 CLI 同一份组装

download() 在 root 作用域的产物经 assembleStaticThemeCss 组装——与 generate-theme CLI 共用同一函数，同参产物逐字节一致：

段 内容 来源
指纹规则块 --x-theme-static: 2|…（v2 15 字段） 构建时写入文件头
三块样式 基础变量 → 主题标尺 → 语义色 root.toStyles()，与运行时注入同源
维度烘焙守卫块 :root:not([data-X]) 形默认值 下载时刻的 dark / size 等当前状态
产物结构实测
指纹字段（15） -
基础变量段 -
主题标尺段（/* colors */） -
语义色段（/* Semantic Colors */） -
守卫块段（/* baked defaults */） -

在左侧控制面板切换暗色或尺寸后「重新解剖」：指纹尾部 6 个维度字段随当前状态变化， 守卫块段出现/消失——这正是「下载时刻状态烘焙为默认」的含义。

下载后怎么用：作静态层挂 <link>
<head>
  <link rel="stylesheet" href="/theme/autospark_root.css" />  <!-- 静态层在前 -->
  <script type="module" src="/app.js"></script>          <!-- 运行时水合在后 -->
</head>

运行时 root 作用域水合后比对指纹前 9 个颜色字段：一致则跳过三块注入 （零 JS 首帧已由静态层保证）；不一致则告警并回退动态注入—— 与 generate-theme CLI 产物走完全相同的接管链路（ADR-0004）。
