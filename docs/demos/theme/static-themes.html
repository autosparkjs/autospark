特性说明：静态主题包与静态样式层

主题库的样式分三层，可独立使用也可叠加：

层内容产物 / 入口
静态样式层reset、工具类、组件类、灰阶常量、图标、动画dist/index.css（Less 编译）
运行时主题层主题标尺、语义色、模式 / 色彩 / 尺寸变量、派生层运行时注入 <style>
静态主题包11 套写死的主题标尺（data-theme=blue 等）src/themes/*.less → dist/themes/*.css
  • 静态主题包不经运行时：给元素挂 data-theme="blue" 即得该套色阶
  • 本页引入的 /autospark/autospark-theme.css 正是静态样式层的全量编译产物（docs.less 聚合）
  • 运行时层与静态层叠加时，运行时注入的标尺特异性更高、按暗色规则反转，两者不冲突
11 套静态主题：每格一个 data-theme 属性

每格挂 data-theme="名称"，色条为各自的 --x-color-theme-0..9。 注意各文件的方向与 color-scheme 声明并不统一——先用色条核对再决定用法。

方向对照表
声明文件方向
color-scheme: light cyan / green / lime / orange / yellow theme-0 最浅 → theme-9 最深
color-scheme: dark blue / dark / magenta / purple / red / volcano theme-0 最深 → theme-9 最浅

静态主题文件是按各自使用场景生成的历史产物：在亮语境里引一份「theme-0 最深」的文件， 背景取到的会是最深档。使用前请核对它的 color-scheme 与色阶方向。

引入方式（构建期聚合入口只含 styles/index.less）
import "…/dist/index.css";              // reset / 工具类 / 灰阶 / 图标
import "…/src/styles/input.less";       // Firefox 焦点框微调（未进聚合）
import "…/src/components/index.less";   // card / button / alert / input（未进聚合）
组件类消费的是 --auto-* 派生变量——不引运行时时需要自带一份语义变量， 或改用静态主题包 + 少量自定义 --auto-*。
把运行时产物静态化：scope.toStyles()
const css = ThemePro.root.toStyles();  // 基础变量 + 语义色 + 主题标尺
// 构建期取出落成 .css 文件 → 「静态化的运行时主题」
（点击按钮生成）

这条路径适合「要运行时主题的全部变量、但不想在页面里跑运行时」的构建期方案： 用 toStyles()（或 download()）在构建脚本里生成 CSS， 产物与运行时注入的内容同源。
