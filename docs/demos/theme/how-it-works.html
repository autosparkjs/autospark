特性说明：从「一个主题色」到「整套界面变量」

主题库不存任何一套写死的皮肤：给它一个主题色，它在浏览器里按 Material 风格色板扩散算法算出四份调色板，再合成「基础调色板」，最后由基础调色板派生出 --auto-* 语义变量供组件消费。 

主题色（种子）
  → ① 主题调色板 + 反转主题调色板        （算法生成，随输入亮度自动适配）
  → ② 灰度调色板 + 反转灰度调色板        （静态灰原料的两个方向）
  → ③ 基础调色板 --x-color-0..9 / --x-bgcolor-0..9   （按 dark / colorized 选择上述哪一份）
  → ④ 派生变量 --auto-*（边框 / 面板 / 表单 / 文字 / 交互态…）
  • 只有主题色需要调：dark / colorized 两个开关切换基础调色板， 即得 light / light+colorized / dark / dark+colorized 四种颜色模式
  • 任意主题色都好看：梯度按输入色的亮度扩散，亮色种子与暗色种子各自得到单调梯度， 不需要为每个品牌色手工配 10 档
  • 其余主题要素同构：字体 / 圆角 / 阴影 / 间距 也是「一套五档基础量 + 一个 data-* 档位开关 + --auto-* 派生」
① 四份调色板（左列为默认亮语境，右列为 data-dark 语境）
亮语境（无属性）
主题调色板 --x-color-theme-0..9（0 浅 → 9 深）
灰阶方向 --x-plain-color-0..9（0 最深文字）
灰阶背景方向 --x-plain-bgcolor-0..9
暗语境（data-dark）
同一族变量：主题梯度反转（0 深 → 9 浅），灰方向也随之反转
灰阶方向 --x-plain-color-0..9（暗块声明的另一份方向）
灰阶背景方向 --x-plain-bgcolor-0..9

固定的灰度原料是 --x-color-gray-0..9（静态层常量，与主题无关）； 主题与灰度的「方向」由亮 / 暗两个模式块各自声明成 --x-plain-*（灰方向）与 --x-tinted-*（多彩映射）别名，基础调色板只负责引用其中一份。

算法输出的是 10 个具体色值：种子色落在与它 CIEDE2000 色差最小的基准色板档位上， 其余档位按该基准色板的明度 / 彩度系数扩散——所以任意色值的种子都能得到一条单调、均匀的梯度。

② 基础调色板 × 两个开关 = 四种颜色模式

四卡内容完全相同（只消费 --x-color-* / --x-bgcolor-* / --auto-*），仅容器上挂的 data-* 属性不同—— 右侧面板切换主题色，四卡同时跟随；切换暗色 / 多彩，只有未固定属性的卡跟随。

light（无属性）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
light + colorized（data-colorized）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
dark（data-dark）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color
dark + colorized（data-dark data-colorized）
面板头部 --auto-panel-header-bgcolor
主文字 --auto-color
次要文字 --auto-secondary-color
辅助文字 --auto-third-color

--x-color-* / --x-bgcolor-* 是「基础调色板」—— 真正随模式与色彩切换的一组变量，业务自定义样式最该引用它们； --x-color-gray-*（固定灰）与主题色梯度组合成这套基础调色板。

③ 派生变量 --auto-*：组件只消费这一层
派生变量（组件消费） 配方（引用基础调色板）
--auto-color var(--x-color-1) 主文字
--auto-bgcolor var(--x-bgcolor-0) 面板底
--auto-border 1px solid var(--auto-border-color) ← var(--x-color-6)
--auto-panel-header-bgcolor var(--auto-secondary-bgcolor)（bgcolor-2 45% 透明）
--auto-input-* 转发 --auto-border / --auto-bgcolor / --auto-font…
--auto-theme-color var(--x-color-theme-5)（暗色提档到 theme-6）

「换一个主题色，整套界面跟着变」的实现终点就在这里：派生层引用基础调色板， 组件引用派生层。改主题色 → 基础调色板重算 → 派生层自动跟随，不需要改任何组件代码。
