只引静态样式层：组件类照样可用
静态层提供的组件类
.auto-alert.info
引入方式（构建期聚合入口只含 styles/index.less）
import "…/dist/index.css";              // reset / 工具类 / 灰阶 / 图标
import "…/src/styles/input.less";       // Firefox 焦点框微调（未进聚合）
import "…/src/components/index.less";   // card / button / alert / input（未进聚合）
组件类消费的是 --auto-* 派生变量——不引运行时时需要自带一份语义变量， 或改用静态主题包 + 少量自定义 --auto-*。
