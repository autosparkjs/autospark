③ 无标题无动作：header 不渲染，closeable 决定浮动 x 的去留

header 只看内容（标题/图标/顶区动作）——无内容时不渲染，不为空 header 付一行高度； closeable: true（缺省）时 close 转根级浮动形态（右上角绝对定位）， false 则连浮动 x 一并去除（消费者自供关闭路径）

内部组件：三个覆盖物都复用同一个轻量内容组件，只负责显示占位正文 + 一个内置 close() 按钮； 骨架 chrome（title / icon / actions）由 autospark.overlay 骨架组件渲染，与内容组件正交
