① 紧凑面板：closeable:false + 无标题无动作 + padding:0 + border:false

骨架 chrome 全部有内容才渲染——header 消失后 close 按钮一并失效，消费者必须自供关闭路径； border:false 卸掉外壳边框 / 背景 / 圆角，面板视觉完全由内容自持

② CSS 变量换肤：保留骨架 chrome，只换视觉

骨架视觉走 --autospark-overlay-bg / -border / -radius / -divider / -hover 等变量 （主题系统统一驱动）；面板根挂 data-overlay="组件名" 契约属性，可按名定向定制

整体替换面板形态（自定义 shell）见下一节「面板外壳」——视觉定制只调整骨架变量，模态行为不变

零骨架 chrome 的紧凑面板——没有 header、没有外壳边框与内边距，视觉完全由内容组件承担。

骨架 chrome 完整保留——深色背景、圆角、分割线、按钮描边全部来自 [data-overlay="themed"] 上的一组 CSS 变量覆盖。
