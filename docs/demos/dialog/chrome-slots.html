① x-slot:title 富文本标题（icon / close 保留）+ x-slot:actions.right 自定义按钮

title 是局部替换——配置式的 icon 与 close 按钮照常渲染； 底部右区按钮完全自定义（样式 / 文案 / 行为）

② 点分名归位：x-slot:actions.top（header 右侧）+ x-slot:actions.left（footer 左区）

顶区动作与标题、close 共处 header；左区动作独占 footer 左侧——右区无内容时 footer 右区不渲染

③ x-slot:header 整块替换——close 按钮一并消失，消费者自供关闭路径

header 出口有内容时默认结构（含 close）整体让位——自定义头部必须自己提供关闭按钮

优先级：slots 重载 > 配置式——两者同声明时 slots 胜出；内容组件 def.slots 声明过的名字归内容组件，骨架 chrome 名永不抢占

这段正文来自内容组件的默认渲染——标题 / 动作区 / 整块 header 都是宿主子级 x-slot:名 重载的骨架出口，与本组件正交。
