四种装饰（decorate 项键，点击切换）

指示色统一取主题色（有 type 时语义色）：solid 勾选态点亮实底反白字（覆盖 variant 表达）、icon 最左 1.2em 占位显示打勾 ✓、corner tone 描边 + 右上角小三角内嵌反白打勾（按压即预显描边，松手切换正式化）、ripple 占位显示涟漪动画指示（呼吸点 + 扩散环，CSS 自绘）。icon / ripple 为占位型：组内任一态佩戴即全组常驻占位，未佩戴态留空、勾选/取消零布局跳动。

装饰与 button props 叠加（每态一景，点击循环）

状态项可携带 Button 全部 props（variant / type / label / icon...）与 decorate 叠加——左：三态循环各态不同装饰与形态整貌换装；右：双态「同意 ↔ 已同意」文本随态改写 + icon 装饰占位恒驻（states 数组一律放外层状态路径引用）。
