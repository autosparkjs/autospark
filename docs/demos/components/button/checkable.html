三种选中渲染（check-style，点击切换）

指示色统一取主题色（有 type 时语义色）：solid 勾选点亮实底（默认）、icon 最左固定占位显示/隐藏打勾（背景不变、无布局跳动）、corner 描边 + 右上角小三角内嵌打勾指示——三角直角边随按钮圆角半径走弦线，紧贴描边右上角、圆角档位切换自动跟随。

x-model 多按钮绑定同一变量（化身 checkbox）
all = {{ all }}（恒布尔，任一按钮点击全体联动）

与原生 checkbox 一致的布尔语义：多枚按钮 x-model 绑同一变量即「全选组」——任一按钮翻转，其余按钮视觉即时跟随；配 x-model.boolean 类型保真。

check-values 任意值 + value 通道
picked = {{ picked }}（"on" / "off"）

:check-values="['on','off']"（放外层状态引用）定义 checked/unchecked 值——点击经 change 冒泡回写（detail.value 为 checkValues 语域值）；x-model 通道与 value 通道并存、按需选用。

表单提交（内嵌真 input 的 name/value）

提交后此处显示表单数据（勾选项以 name=on 提交，未勾选不提交——原生 checkbox 语义）。
