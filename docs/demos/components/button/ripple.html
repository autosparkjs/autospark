点击涟漪（默认）：ripple: true ≡ { trigger: "click", inside: true }

自点击点铺开、约束在按钮内部、圆角跟随，播一个完整周期自止、连点取消重起——按钮涟漪的缺省形态。

触发器（trigger）：点击 click / 始终 always / 悬停 hover

click 播一个周期自止（缺省）；always 自中心持续循环；hover 移入播放、移出播完当前周期即停。

动画形态（type）：inside 内部铺开 / echo 双环回声 / ring 外扩环 / glow 光晕呼吸

inside（缺省）自点击点在按钮内部铺开；inside: false 后切换为外扩族——echo 双环回声 / ring 单环外扩 / glow 光晕呼吸。inside 与外扩形态互斥（同时声明时 type 被 warn 忽略）。

视觉参数：color / speed 透传

ripple 对象即 x-ripple 的 props 值，全部键面（color / size / speed / gap / badge…）透传——完整词表见 x-ripple 指令文档。
