图标名（字符串形态）

字符串即内置图标名；尺寸跟随字号档位（默认 1em），颜色继承按钮内容色。

对象形态 · size（尺寸系列）

对象形态 { name, size, color, strokeWidth, padding }——name 必填；size 数字（px）或任意 CSS 值。

对象形态 · color（独立配色）

color 覆盖继承（按钮内容色），任意 CSS 颜色值。

对象形态 · strokeWidth（描边粗细）/ padding（内距）

strokeWidth 经 --as-icon-sw 变量下发（含网格补偿）；padding 为图标与文字间距留白。

对象形态 · badge（右上角角标）

badge 为 x-icon 同款标量三形态——形态即启用：true（缺省板距 2px）/ 数字（板距 px）/ 字符串（任意 CSS 值）；角标圆点取 --auto-danger-color 语义色，板距即角标周围留白。

图标位置（label-pos：left | right | top | bottom | none，默认 right）

label 在 icon 的哪侧——left 时图标移内容区末尾并与 tags 互换（loading 随行）；none 不显示文字区（label+memo 一并隐藏），label 文本自动转挂悬停提示（tooltip 插件在场挂 data-tooltip、缺席挂原生 title，显式提示优先）；check-style icon 的勾选占位恒最前。

与其他特性组合

对象形态与 labelBelow / memo（图标 2 倍规则）、菜单形态、语义色等自由组合；对象须放外层状态再 :icon="conf" 路径引用（字面量嵌套对象 props 会触发引擎更新环缺陷死锁页面）。
