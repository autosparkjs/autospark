clearable（值非空时显形，点击清空 + 焦点回控件）

清除经 input 事件冒泡驱动 x-model 回写（当前值：{{ kw || '（空）' }}）。

prefix / suffix（string 文本 | { icon } 图标）

图标对象 props 经状态引用注入（iconConf），避免值对象内字面量对象的引擎缺陷。

maxlength + showCount（超限染红）

maxlength 同步原生属性（浏览器原生截断），计数器显示「len / max」。

装饰插槽（重装饰层，投影接管出口位）

呈现序恒为 [插槽前] 控件 [清除][眼睛][计数] [插槽后]——props 前后缀装饰与插槽同轨出口位（消费方投影接管时 props 装饰让位，显式接管语义；装饰上提见 Field）；插槽内交互件标 data-autospark-action 自理焦点（详见 Field）。
