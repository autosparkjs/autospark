prefix / suffix 具名插槽：消费方任意内容，默认次要色

当前值：{{ price || '（空）' }} —— 宿主直接子级以 <template x-slot:prefix> / x-slot:suffix 标记分段；空插槽整出口静默消失（template 载体，零多余 DOM）。

插槽内交互件：data-autospark-action 自理焦点

点击装饰（🔍 / 空白区）焦点落控件；标记 data-autospark-action 的按钮点击不转发焦点（动作件自理）。

轻装饰 / 重装饰分层：input 的 props 前后置 + 插槽前后置共存

呈现序固定 [slot:prefix] [props前缀] 控件 [动作件] [props后缀] [slot:suffix]——props 轻装饰贴控件（文本/图标），插槽重装饰恒在外侧（任意 HTML），两者共存不互斥（ADR-0020 修订）。
