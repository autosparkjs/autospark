最小用法：默认出口装原生控件 + 盒饰选配类，x-model 直达内层

当前值：{{ name || '（空）' }} —— 宿主挂 asc-field-box 得盒饰 chrome，内层控件标 data-autospark-control 接管禁用/焦点/aria 同步。

状态色通道（status：error / warning / success）

status 染 --asc-field-tone 中转变量：未聚焦即染边框，聚焦补同色光晕；error 态自动同步控件 aria-invalid。

disabled / readonly（同步原生控件 + 宿主反射）

props 同步到 data-autospark-control 标记控件（disabled / readOnly）+ 宿主 data-disabled / data-readonly 反射（CSS 淡化/光标通道）。

尺寸档位（主题通道 data-size，挂任意祖先容器）

字号/字体族/内距/圆角经 --auto-* 主题变量全跟随（三级回退链，无 theme 环境吃校准兜底字面值）；试试右上角控制面板切档位/暗色。
