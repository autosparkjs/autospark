多行文案（content 数组 / JSON 字符串声明）+ 自定义样式

多行文案：content 传 string[]（状态引用注入）逐行绘制，行高 1.3 倍字号。

本例自定义：rotate -30° / fontSize 14 / gap [120, 80] / color 品蓝半透明。

声明形态：裸 content 传 JSON 数组字符串（经 data-content 标量通道，规避字面量数组 props 死环）。

gap="60" 数字等两轴（[60, 60]）。

font 速写一键覆盖（"bold 24px serif"——完整 CSS font 语法直传 canvas）；opacity 整层不透明度。
暗色态（容器裸挂 data-dark）

色值取主题次要色三级回退：主题在场自动跟随暗色；无主题 + data-dark 时兜底字面值切换为亮色校准值。
