容器水印：内容区平铺（rotate -22° / 间隙 100）

被水印覆盖的内容区：watermark 缺省为容器形态——水印层 absolute 铺满组件、覆盖在默认插槽内容之上。

水印恒 pointer-events: none——下层内容照常交互（选中文本、点击按钮均不受阻）。

canvas 离屏绘制旋转文本单元 → data URL 平铺背景；文案色取主题次要色（暗色自动跟随提亮）。

content 文案 / rotate 旋转（缺省 -22）/ gap 间隙（缺省 100）/ opacity / zIndex 均可调；多行文案传数组（见形态页）。

全页水印（full-page 裸属性糖）：铺满视口

fullPage 时水印层挂 body、fixed 铺满视口（zIndex 默认 9）；关闭即收除。
