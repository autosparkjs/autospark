基础横排（level 1 横排 · 子级 bottom-start 向下弹出 · value 激活）

mode="horizontal" 横排 level 1，所有子级一律走弹层：level 2 向下（bottom-start），level 3+ 向右级联。两档菜单共享 active —— 任意一处点击，另一处激活态同步迁移。

触发方式（缺省 hover / trigger="click"）

hover 悬浮即展开（带意图延迟）；click 点击开关、外点关闭 —— 触屏路径推荐 click。子项 conf.trigger 可逐级覆盖菜单级设置。

项形态（icon / 分隔线 / 禁用 / checkable）

横向单个 checkable 项同样切换勾选集合（value 为 string[]）；禁用项不响应；竖线为 '-' 分隔线，横排下保留项间小间距。
