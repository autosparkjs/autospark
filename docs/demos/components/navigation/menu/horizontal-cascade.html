多级级联（二级向下 / 三级起向右 · 弹层骨架 title / closeable）

水平模式没有缩进域：level 2 面板 bottom-start 向下展开，level 3+ 面板 right-start 向右级联，任意深度递归。children 对象形态即 SubmenuOptions，title / closeable 等骨架键直接透传 x-popover。

定位与外观定制（conf.at.placement / border / trigger 逐级覆盖）

第一个父项把面板改为 right-start 并关闭边框；第二个父项改用 click 触发（覆盖菜单级 hover）。显式 conf 键赢过 menu 自动计算值。
