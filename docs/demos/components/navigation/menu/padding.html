padding 三形态（虚线框 = 容器边界，观察留白）

缺省 calc(var(--auto-spacing, 0.8rem) * 0.5)（theme 未加载兜底 0.4rem）； number → px；string 原样。作用于 .asc-menu-main 与弹层面板，header / footer 分区不跟随。 卡头按钮切换折叠——折叠态内边距同样生效

分割线与菜单项同宽 + group 分组标题（secondary 色）

分割线左右 margin 为零——与菜单项同宽，缩进全部由 main 内边距承担（右图 padding: 0 时贴边可见）； type: 'group' 分组标题为次要色 --auto-secondary-color（含 dark 兜底链）； 折叠态无图标的分组标题不渲染

padding 同步作用于弹层面板（popLevel 弹层：展开一级后 hover 子项）

点击「更多操作」展开缩进子组，再 hover 其中带子菜单的项弹出——弹层面板在 overlay 容器、 CSS 继承断，padding 经 popover props 管道显式下传，弹层内边距与本体一致（递归面板逐层传递）； 折叠态子菜单全部弹层（hover 一级项即弹出，无需展开）
