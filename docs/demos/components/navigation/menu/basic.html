items 状态引用 + x-model 双向 + 子菜单点击展开

菜单项 { key, label, icon?, disabled?, children?[]（一层子菜单嵌套）} 恒经状态引用注入 （字面量数组 props 死环规避）；带 children 的父项点击展开/收起，叶子项激活； 激活值指向子项时祖先链自动展开。等价受控形态：:value="active" + 外层 @change="active = $event.detail.value"。

子元素声明（静态菜单树，含嵌套 children）

<x-menu-item> 声明经 precompile 变换折叠为 items JSON（data-items 通道， 规避字面量数组 props）；嵌套声明子项折叠为 children；value 静态折叠激活。
