slotDir="horizontal"（Logo 最左 · header 左 · 列表居中 · footer 右）

slotDir 只改变根菜单 header / footer 的摆放：horizontal 时 header 在左、footer 在右、列表居中撑满；Logo 区始终排在最前。作用域插槽形参按需解构，随状态刷新。

slotDir="vertical"（缺省：header 上 / footer 下 · Logo 在 header 之上）

水平模式下 vertical / horizontal 两种 slotDir 都可用；只有垂直折叠态才强制纵向。水平折叠不改写 slotDir。
