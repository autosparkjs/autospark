右侧菜单的 :logo 绑定 computed 组装对象（控件改动整包替换——props 原地变更不发信号）。 「失效图」演示 img 加载失败 → 首字符块兜底；折叠时只渲染 logo 图标

快捷与对象形态（string ≡ { icon } · 图片 URL / 图标名一体两用）

左：logo 传图片地址（data: URI）→ 渲染 <img>；右：logo 传图标名（对象形态 { icon, title, description }）→ <i x-icon> 渲染 + 标题 / 描述文字。 卡头按钮切换折叠——折叠时只留 logo 图标

direction / shape / aspectRatio / url 定制（静态预设对照）

左：direction: 'vert' 纵排居中；中：aspectRatio: 2 横长展示区 + shape: 'none' 无裁剪 + url 点击跳转；右：shape: 'circle' 圆形裁剪（shape: 'radius' 圆角矩形为缺省）。 direction: 'auto'（缺省）按菜单宽度切换——容器 ≥160px 横排、更窄纵排（含折叠窄条）

图失效兜底 / 折叠只留图标 / slot=logo 重载

左：图片加载失败 → 圆角矩形首字符块兜底（跟随 shape）；中：折叠时只渲染 logo 图标 （title / description 隐藏，居中适配 collapsedWidth）；右：<template x-slot:logo> 作用域插槽重载整个 Logo 区（形参同 header / footer，折叠形参随状态刷新）
