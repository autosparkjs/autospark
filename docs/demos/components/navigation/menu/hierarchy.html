expandLevel：初始展开到第 N 级（0 全折叠 / 1 缺省 / 2 到二级）

expandLevel 只管「初始默认」——运行时点击父项随时折叠 / 展开（openKeys 接管）

popLevel：level > popLevel 的子菜单走 popover（0 全缩进 / 1 混合，悬浮展开）

悬浮父项弹出（hover 触发，delayShow 意图延迟）；弹层内更深层级继续级联；expandLevel 只作用于缩进域

openKeys：全受控展开态（显式 true / false 优先于 expandLevel 默认）
