基础用法（受控 current + clickable 点击切换）

items（{ title, description?, icon? }[]，状态引用注入）驱动步骤；先行步自动打勾、 连接线随完成染色；clickable 开启后点击步切换（change 冒泡 detail = { current }， 外层一行回写——当前步 {{ step + 1 }} / 共 3 步）。

子元素声明（静态步骤）

<x-step title description icon> 经 precompile 变换折叠为 items JSON （data-items 通道，规避字面量数组 props）；current 静态折叠（数字类型推断）。
