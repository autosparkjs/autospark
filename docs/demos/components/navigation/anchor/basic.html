affix 固定侧栏：滚动联动高亮 + 点击平滑滚动（当前锚：{{ cur }}）

items（{ key, label, href? }[]）恒经状态引用注入（secs 为页面状态）；href 缺省 key 作锚 id（#key）；滚动到哪高亮哪，点击平滑回到该区块（不写 hash——纯滚动语义）。

概述

锚点导航适用于长文档页：侧边列出各区块入口，滚动位置实时联动高亮。

用法

向下滚动观察右侧锚点高亮迁移；点击任一锚点平滑滚回对应区块。

API 参考

props：items / offset / affix；事件：change（冒泡，detail = { key }）。

常见问题

页顶（全未达线）不高亮——antd 缺省语义；判定线可用 offset 偏移补偿吸顶条高度。
