items 状态引用 + x-model 双向 + 面板区（x-show 切换）

面板 A：x-show 切换（DOM 保留，输入态不丢）。

面板 B：默认插槽内以消费者状态切换。

面板 C：禁用项跳过（键盘序列同理）。

页签头由 items（{ key, label, icon?, disabled? }[]，状态引用注入）驱动；面板写在默认插槽内， 绑同一状态。等价的受控形态：:value="view" + 外层 @change="view = $event.detail.value"。

子元素声明（静态页签头）

<x-tab key label icon disabled> 经 precompile 变换折叠为 items JSON （data-items 通道，规避字面量数组 props）；面板区同样走默认插槽。
