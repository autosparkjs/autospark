零配置即 check 按钮（缺省组）

不传 states 即缺省组 [{value:false},{value:true,decorate:'corner'}]——点击在未勾选 ↔ 勾选（右上角打勾角标）间循环；受控回写经外层 @change。

三态循环（states + 每态视觉）

点击循环 next（尾态回卷）；每态携带 button props 全集（variant/type/icon/label...）+ decorate 装饰——切换即整貌换装（形态/语义色/图标/文案全变）。

灰色无匹配态 + autoswitch 纯受控

左：value 初始为域外值 → 灰色无匹配态（可点击进首态）；右：autoswitch="false" 点击不切换，外层经 dataset 反射读当前值自行裁决回写。

表单桥（x-model 布尔保真 + hidden 提交）

布尔组化身 checkbox（x-model.boolean 保真、未勾选不提交）；三态组内嵌 hidden input（提交 mode=当前值）——submit 后观察 URL。
