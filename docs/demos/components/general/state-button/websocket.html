WebSocket 连接状态机（异步拟真：autoswitch=false 外层驱动）
状态：{{ ws }}　日志：{{ wsLog }}

真实连接的切换时机归异步回调而非点击——autoswitch="false" 纯受控，点击只发起动作， ws.onopen / ws.onclose（此处 setTimeout 模拟握手 800ms / 挥手 600ms）到达才写 value。 四态各持一套 button props：未连接虚线中性、正在连接warning 实底 + loading: true 转圈自动禁点（连接中物理不可再点，引擎四重判定链的 !loading）、 已连接success 实底 + icon + ripple 涟漪指示（呼吸点 + 扩散环随语义绿）、正在断开warning 文本 + loading。 「模拟服务器断开」演示外部事件注入 value（onclose 意外触发，不经点击直接落回未连接）。
