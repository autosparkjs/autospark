化身 checkbox 表单字段（受控半双工）

内嵌隐藏真 input[type=checkbox]——checkable="true" 即标准 checkbox 表单字段； 默认渲染 checkStyle: 'corner'（右上角打勾角标），点击翻转 value 并冒泡 change （外层 @change 回写受控）。

checkStyle 四种选中渲染（点击切换）

指示色统一取主题色（type 非默认时语义色）：solid 勾选点亮实底、check 最左 1.2em 常驻占位显示打勾（背景不变、零布局跳动）、corner（默认）描边 + 右上角小三角内嵌反白 打勾（按压即预显描边）、ripple 勾选时宿主整体恒开 x-ripple echo 双环涟漪（always 常驻、外扩形态；取消回退点击涟漪）。

x-model 双向（.boolean 保真）+ 表单提交

宿主 x-model 走组件桥布尔语域（配 .boolean 保真，变量须在根 state / x-data 域）； 勾选以 name=String(checkValues[0]) 提交、未勾选不提交（原生 checkbox 语义）。
