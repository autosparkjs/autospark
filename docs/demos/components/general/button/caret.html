尾部箭头（caret）：最右端 x-icon arrow，按方向旋转——切换时同一图标连续转动
caret = {{ dir }}

caret 只做方向指示，不改变点击语义；与 tags 并存时恒居最右端。方向切换复用同一枚 arrow 的 x-icon 旋转（默认 0.3s，可经 --as-icon-rotate-duration 调整）。

浮动箭头（float-caret）：脱离标签行流，绝对定位到按钮右上角（top / right 等距）、尺寸减半——叠加指示形态（默认 false）
floatCaret = {{ floatOn }}

浮动态不占标签行空间（label 截断可用宽不含它，尾部可能被叠压）；与 tags 并存时 caret 叠于其上——组合视觉按需取舍。
