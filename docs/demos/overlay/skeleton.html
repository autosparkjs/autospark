① 同一内容组件 × 同一份骨架配置，三种消费者形态

三个按钮打开同一个 notice 组件：模态（x-dialog）/ 悬浮（x-popover， .click 点击触发）/ 侧滑（x-drawer）。 title / icon / actions 三键字面一致—— header（标题 + 顶区动作 + 关闭按钮）与 footer（底部动作区）在三形态中表现一致： 三内置 shell 内嵌的是同一个骨架组件 autospark.overlay。

② 骨架动作双通道：声明式 scope actions 表 + 配置式合并覆盖

声明式通道：<script type="autospark/actions"> 注册进消费处 scope 的 actions 表，显式声明 pos ∈ {top, left, right} 才准入 （无 pos 的页面级 action 不上屏）；配置式通道：x-dialog-options.actions。 两通道打开时合并，同 id 后进覆盖先进（配置式在后）——左区「标记已读」是配置式覆盖版， 声明式文案被顶掉；pageLevel 无 pos，注册了却不进骨架（下方按钮可点，证明它在表里）。

最近动作：（无） —— 动作按钮由骨架渲染（与内容组件正交）；popover 额外附形态配置（.click + delayShow: 0），骨架五键不受影响。
