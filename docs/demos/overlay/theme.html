覆盖物 × 主题：弹层开着也能换肤

打开任意弹层后，在右侧面板切换主题色 / 暗色模式 / 多彩 / 圆角阴影维度—— 覆盖物面板（渲染在 body 容器下）与页面同步实时跟随。这是三级样式回退链的第一级 （--auto-* 派生令牌）在生效；未引入 theme 时回落到 --autospark-overlay-* 覆盖变量与校准兜底值（视觉与默认主题基本一致）。
