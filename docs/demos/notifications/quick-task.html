task 模板自带 暂停/停止/取消 控制钮（四控制键）；下载中再次点击本按钮 = 取消
return 初始 props 立即弹卡，下载闭包实时推进进度条
task() 返回 Task 会话：进度 progress/complete + 六控制动词 start / pause / resume / stop / cancel / close（各配 on<动词> 订阅 ——按钮点击与程序直调同发 actions/<动词> 事件）；session.abortSignal 恒可用（停止/取消/× 触发中断）。factory 形态 task(async (session) => ...) 收到的挂起会话即 Task 实例（type 已锁定），return 的 props 为初始展示配置。
