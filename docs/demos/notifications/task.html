① 完整生命周期（自动模式 + 外部控制按钮）

创建即 running（首次显示自动补发 actions/start）；页面按钮与卡片自带控制钮同源—— 同样触发状态机与 actions/<动词> 事件。

② 手动开始（canStart 门控）

canStart: true：卡片以 pending 态等待（呼吸条 + 「待启动」），进度被门控； 点「开始」发 actions/start，宿主在 onStart 里才开跑。

③ 闭包内控制（factory + onXxx + abortSignal 协作取消）

factory 写法：return 初始 props 立即弹卡，下载闭包里 session.onStop / onCancel / onClose 响应用户手势、每分块检查 session.abortSignal.aborted 提前退出——真实 fetch 直接把 signal 传给 fetch(url, { signal }) 即中断。

④ 自定义 actions 与内置控制钮共存

用户按钮走标准 actions/<名> 闭环（置已读 → 事件 → handle → hide 判定）， 与内置 暂停/停止/取消 各行排布；hide: false 的 action 点击不关卡。 内置动词（start/pause/resume/stop/cancel/close）是该卡 actions 命名空间的事实保留名。

⑤ 停止 vs 取消分野对比

停止 = abort +「已停止」终态留卡（进度定格，结果可查，closeWhenDone 对 stopped 同生效）；取消 = abort + 立即隐藏（不留结果）。

⑥ 事件观测

通配订阅收 { type, payload } 信封——verb（add/update/show/hide/…）与 actions/*（控制动词 + 用户按钮）全收，再点一次关闭。
