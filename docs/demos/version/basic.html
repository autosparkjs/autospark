点击下方按钮切换 $.version——各元素的 x-version 表达式即时重算显隐（隐藏 = autospark-version-hidden 类， display:none !important）。切到「未知」观察失效语义： $.version 为 undefined 时指令静默短路、全部恒渲染。
当前版本 {{ $.version }}
x-version="2" —— 仅版本 2 可见（裸值 ≡ 相等）
x-version=">1" —— 大于 1 可见（数值有序比较：2 / 2.1 / 3）
x-version="<=2,3" —— ≤2 或 =3 可见（逗号 OR：1 / 2 / 3，2.1 不可见）
x-version="!=2" —— 非 2 可见（1 / 2.1 / 3）
x-version="/^2\./" —— 正则匹配：2.x 系列可见（2 / 2.1）
x-version="2" + x-show="flag" —— 组合：版本隐藏恒胜， x-show 只在版本 2 内有话语权（ ）
