无 button（对照，无动效）：

button（载体 = 图形：hover 加深 / press 缩放）：

button + shape（载体 = 底板：板色梯度加深 / 按下整体缩放）：

组合 @click 　（悬停加深 + 手型光标，按下有缩放反馈）

悬停 / 按下上图标体验动效：未开 shape 时动效作用于图形本身（brightness 加深 + scale 缩放）； 开 shape 时动效作用于底板（浓度基准 5% 依次 +5% / +10%，浓板态 8% 同公式顺延 + 整体 scale 0.94），图形不动。 button 只做视觉可供性——无 role / tabindex / 键盘激活，需要真按钮时包 button 元素。
