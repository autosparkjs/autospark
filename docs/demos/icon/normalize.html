图标归一化（外来图标自动对齐）

收集期自动对齐内置规约——左列自动归一化，右列同源 svg 仅多一个 data-raw 标志作对照

场景 自动归一化 data-raw（原样）
线帽：缺 linecap
→ 补圆头圆拐角
颜色：stroke="#f03d5e"
→ 跟随文字色		 容器文字色 恒为硬编码色
16 网格：视觉粗 1.5 倍
→ 换算 ×2/3（与基准一致）
256 网格：细到近不可见
→ 换算 ×10.7（与基准一致）

每行右侧小图为 24 网格基准（与内置图标同粗细）。归一化对 icons.add()、x-icons 内联、远程 IconifyJSON 三条管道同一核心；fill 体系（填充图标）由类型判定豁免、零接触。全局关闭： AutoSpark.icons.options = { normalize: false }；构建期批量预处理： AutoSpark.normalizeIconSvg(svg)（data-raw 在产物中保留）。
