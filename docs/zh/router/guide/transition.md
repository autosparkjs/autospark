# 转场动画

::: warning 规划中
转场动画特性**尚未实现**——本页描述规划语义，运行时行为会在后续版本落地。
:::

## 关于

转场动画（transition）指路由视图切换时的过渡效果：旧视图淡出、新视图淡入、滑动翻页等。它发生在出口内部的视图激活切换点上，与 router 的导航流程解耦。

## 规划语义

- **作用点**：出口组件内的视图切换（激活 hash 变化）——动画属于视图层呈现，不阻塞导航与数据加载
- **声明方式**：规划经出口 props / 路由项声明过渡类型与时长，复用 engine 的动画能力（`x-animate` 体系）
- **与 keepAlive 的关系**：缓存视图切回时的动画与首次进入一致；临时视图的进出场动画在重编译前后播放

## 当前的替代方案

在特性落地前，可用 engine 的动画指令在视图模板内部自行实现进场效果——远程视图默认经模板编译，`x-*` 指令全部生效：

```html
<!-- views/page.html：视图被激活挂载时播放进场动画 -->
<div x-animate="fade-in-up">
    <h1>页面内容</h1>
</div>
```

出口样式钩子（`.autospark-outlet-view` 等）也可配合 CSS transition 自行定制切换观感，详见[路由出口](./outlet.md#页签模式)。

落地后本页将更新为完整指南。
