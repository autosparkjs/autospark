# 对比评测

主题方案大体分四类：**手写 CSS 变量**、**构建期预生成主题**、**CSS-in-JS 运行时主题**、**运行时变量派生**（本库）。本页逐项对比，并说明为什么本库选了最后一条路线。

## 一张表看差异

| 维度 | 手写 CSS 变量 | 构建期预生成（token 方案） | CSS-in-JS 主题 | **AutoSpark Theme** |
| --- | --- | --- | --- | --- |
| 主题产物 | 人工枚举的变量表 | 每套主题一份静态 CSS | JS 对象 → 运行时样式 | 运行时注入的变量表 |
| 换主题 | 运行时（但值要自己写全） | 通常需重新构建 / 加载对应 CSS | 运行时 | 运行时 |
| 新增一个主题色 | 手工生成 10 阶 + 派生量 | 改配置 + 构建 | 改 JS 对象 | 改一个值 |
| 暗色 | 手写整套暗色变量 | 构建期产出暗色主题 | 视实现 | 内置（标尺反转 + 暗色派生层） |
| 模式 × 色彩组合 | 手写全部组合 | 组合爆炸 | 视实现 | 两维度正交，映射随语境 |
| 局部主题 | 自己设计选择器边界 | 少见 | 依赖组件树 Context | 内置 `addScope` / `data-theme-scope` |
| 首访闪烁 | 无 | 无 | 视实现 | 有（接受），回访零闪 |
| 运行时依赖 | 无 | 无 | 有（样式运行时） | 有（一个色板小包） |
| 视觉回归 | 靠人眼 | 靠人眼 | 靠人眼 | 附带对比度校准脚本 |

## 与「手写 CSS 变量」对比

**相同**：都是 CSS 变量驱动，组件层只消费语义变量，换肤不改组件。

**不同**：

- 本库的**变量值由算法派生**——「浅 3 档」不是常量而是一次计算；手写方案需要人工保证 10 档单调、模式间呼应。
- 本库内置**模式与色彩两个维度**及其叠加映射；手写方案通常只有 `[data-theme=dark]` 一个开关。
- 本库提供**持久化与回访恢复**；手写方案靠 SSR 或静态 CSS 天然规避闪烁。

**什么时候手写更好**：主题固定、不需要运行时切换、也不打算让业务引用色阶档位的场景——零依赖、零 JS，没必要引入运行时。

## 与「构建期预生成主题」对比

（典型代表：Ant Design v5 的 token + 多主题产物、基于设计的静态主题包。）

- **构建期方案的优势**：产物是纯静态 CSS，无运行时开销、无 FOUC；可被设计系统统一管控。
- **本库的优势**：支持**运行时任意色**（用户拖一个取色器就能换主题，`ADR-0003` 的快照恢复也能覆盖自定义主题色）；局部作用域是内建能力；不需要为每个主题跑一次构建。
- **诚实的取舍**：本库**首访会闪一次默认主题**（FOUC）。这一项在方案评估中被明确接受，替代路线（构建期预生成静态主题层）成本高一个量级，且无法覆盖自定义主题色的恢复。

## 与「CSS-in-JS 主题」对比

（典型代表：styled-components / Emotion 的 ThemeProvider、vanilla-extract 的运行时主题。）

- **本库不做样式作用域隔离**：它产出的是 **CSS 变量**，样式本身仍是普通 CSS（或 Less），因此没有 JS 样式运行时的包体积与渲染开销，样式可以被浏览器原生缓存、也可被 `@media` / 容器查询自由组合。
- **本库是「变量层方案」而非「样式层方案」**：它不接管你的组件样式写法，只负责把变量算对。想接入已有 CSS 组件，只要把颜色换成 `--auto-*` 即可。
- **代价**：没有类型安全的样式编排；变量名拼错只有运行时才能发现（可用 `toStyles()` 做静态检查）。

## 与 AutoSpark Engine / Components 的配合

三者分工清晰、命名一致：

| 包 | 职责 |
| --- | --- |
| `autospark`（Engine） | 模板渲染、响应式绑定、事件与组件机制 |
| `@autospark/components` | 纯 HTML 组件资产（`x-define` 模板） |
| `@autospark/theme` | 外观变量与组件类（`--auto-*` / `auto-*`） |

因此 Engine 项目接入主题只需要：引静态 CSS + `import { themeManager }`——组件里的类名（`auto-input` / `auto-btn` / `auto-card`）自动获得主题化外观。

## 选型建议

| 你的情况 | 建议 |
| --- | --- |
| 主题固定、不换肤 | 只引静态样式层，甚至只用预设主题 CSS |
| 需要暗色模式 + 品牌色定制 | 引入运行时，用 `themeManager.dark` / `themeColor` |
| 需要页面内多套主题（预览器 / 编辑器） | 用 `addScope` 建局部作用域 |
| 对首访 FOUC 零容忍 | 本库不合适（除首访外都可控），或自行在服务端输出快照样式 |
| 已有 CSS 组件需要接入 | 把颜色替换为 `--auto-*`，用 `data-*` 属性支持局部切换 |
