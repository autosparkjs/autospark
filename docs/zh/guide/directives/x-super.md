# x-super 叠加默认内容

## 概述

插槽内容默认是**整体替换**：一旦提供内容，默认内容整段让位。`x-super` 是写在**插槽内容里的空标记**——展开时把「本段覆盖掉的默认内容」原位填进标记内部，于是可以给默认内容加前缀、用自定义结构包裹，甚至把它夹在自定义内容中间：

```html
<div x-component:card>
  <template x-slot:header>
    <h3>自定义标题</h3>
    <x-super></x-super><!-- 此处展开 header 插槽被覆盖的默认内容 -->
  </template>
  <p>前缀<x-super></x-super>后缀</p>
</div>
```

标记只在**插槽内容里**生效（组件路径与 `x-dialog` 覆盖物路径同一套语法），且只展开**本段覆盖的那一个插槽**的默认内容。插槽如何声明与投影见 [x-slot](./x-slot.md)。

## 快速入门

组件 `card` 的两处插槽各写了一份默认内容（`默认头 · {{title}}` 与 `默认正文（{{count}} 次浏览）`），demo 对比两次使用：

**看什么**：

1. **第一个面板**——不提供内容，两处插槽显示默认值（对照组）；
2. **第二个面板**——标题为「自定义标题 + 默认头 · 卡片」（标记后置叠加）；正文里默认内容出现**两次**、夹在自定义文字中间（交错 + 多次展开），蓝色徽章是自定义内容的一部分。

<demo html="slot/super.html"/>

对应代码（对照 demo 的第二个面板）：

```html
<!-- 组件：两个插槽各写一份默认内容 -->
<div x-define="card">
  <header x-slot:header>默认头 · {{title}}</header>
  <div x-slot>默认正文（{{count}} 次浏览）</div>
</div>

<!-- 内容：标记处原位展开被覆盖的默认内容 -->
<div x-component:card>
  <template x-slot:header>
    <h3>自定义标题</h3>
    <x-super></x-super>
    <!-- 展开「默认头 · 卡片」，在组件状态求值 -->
  </template>
  <p>
    前缀 → <x-super></x-super> ← 交错 → <x-super></x-super> ← 再次展开
  </p>
</div>
```

## 指南

### 指令值

`x-super` 是**空标记**——没有可用的指令值，也没有修饰符，全部语义由「写在哪一段插槽内容里」决定：

| 形态                                | 用在哪               | 说明                                             |
| ----------------------------------- | -------------------- | ------------------------------------------------ |
| `<x-super></x-super>`               | 插槽内容内（任意处） | 展开本段覆盖的默认内容，标记保留为包裹层         |
| `<x-super/>`                        | —                    | **不合法**：自闭合斜杠被忽略，吞掉后续兄弟节点   |
| 写在插槽内容之外（普通模板 / 默认内容里） | —                | 警告「仅在插槽内容内生效」，保留为空元素         |

### 语义要点

- **恒为自引用**：标记展开的是**本段**覆盖的默认内容——`header` 内容里的标记展开 `header` 的默认内容，不跨插槽引用；
- **多次出现各自独立**：同一段里写 N 次，就独立展开 N 份（各自的 `{{}}` 依赖独立响应）；
- **两段状态互不混淆**：展开的默认内容在**组件自身状态**求值（它本就是组件的一部分），自定义内容照旧在**使用处状态**求值；
- **与作用域插槽正交**：内容声明的形参只管自定义内容的求值，展开的默认内容恒为组件语境、不接收形参；
- **继承组件的叠加**：组件经 `x-define:inherit` 覆盖过默认内容时，标记展开的是**覆盖后的最终默认内容**；
- **覆盖物路径同语法生效**：`x-dialog` 等覆盖物的内容里写法一致，见 [x-slots](./x-slots.md)。

```html
<!-- 展开的默认内容读 {{title}}（组件状态），自定义内容读 {{label}}（使用处状态） -->
<div x-data="{ label: '外层' }">
  <div x-component:card>
    <template x-slot:header>{{ label }} · <x-super></x-super></template>
  </div>
</div>
```

### 边界规则

| 情况                                          | 结果                                         |
| --------------------------------------------- | -------------------------------------------- |
| 出口没有声明默认内容（空插槽）                | 静默展开为空                                 |
| 标记写在插槽内容之外（普通模板 / 默认内容里） | 警告「仅在插槽内容内生效」，标记保留为空元素 |
| 标记写成自闭合 `<x-super/>`                   | 斜杠被忽略、吞掉后续兄弟节点，警告并丢弃误吞内容 |

```html
<!-- ✗ 自闭合：后续兄弟节点全被吞进标记 -->
<template x-slot:header><x-super />后面的节点会被吞掉</template>

<!-- ✓ 空标记 + 双标签 -->
<template x-slot:header><x-super></x-super>后面的节点安全</template>
```

::: warning 必须双标签写法
`<x-super></x-super>` 是空标记，但**不能写成自闭合 `<x-super/>`**——HTML 解析器不认未知元素的自闭合形式，斜杠会被忽略、后续兄弟节点全部被吞进标记内部（引擎会警告并丢弃误吞的子节点）。
:::

### 包裹层与样式

标记元素**保留为包裹层**（与插槽出口标记同理：展开的默认内容需要宿主、也便于 CSS 定位）。不希望它参与布局时加一条样式即可：

```css
x-super {
  display: contents; /* 包裹层布局透明 */
}
```

## 注意事项

- **必须双标签**：写 `<x-super></x-super>`，自闭合 `<x-super/>` 会吞兄弟节点（警告 `x-super: 标记应为双标签空元素写法`）；
- **只在插槽内容里生效**：写在普通模板 / 默认内容里只得到警告与空元素（`x-super: 仅在插槽内容内生效`）——挪进插槽内容；
- **嵌套组件不穿透**：组件内容里的标记归**内层**插槽解析，不会展开外层的默认内容；
- **展开内容不接收形参**：作用域插槽的形参只作用于自定义内容，展开部分恒为组件语境；
- **标记是包裹层**：需要参与布局可直接当容器写 CSS，不需要就 `display: contents`；
- **继续阅读**：插槽声明、内容投影、作用域插槽与动态插槽见 [x-slot](./x-slot.md)；覆盖物的内容归属见 [x-slots](./x-slots.md)；组件继承见 [x-define](./x-define.md)。
