# x-slots 覆盖物内容归属

## 概述

`x-slots` 是写在**覆盖物宿主**（挂了 `x-dialog` 等消费者的元素）上的**内容归属容器**：同一个宿主上声明了多个覆盖物消费者时，每份内容必须各套一个 `x-slots="组件名"` 容器，引擎才知道「这份内容该投影给谁」。

```html
<!-- 单消费者：内容标记直写宿主子级，不需要容器；按钮标签照常留在按钮上 -->
<button x-dialog:confirm="ui.open">
  <div x-slot>要确认吗？</div>
  打开
</button>

<!-- 多消费者：同一元素两个 x-dialog，内容各套归属容器 -->
<button x-dialog:save="ui.save" x-dialog:cancel="ui.cancel">
  <template x-slots="save">保存当前草稿？</template>
  <template x-slots="cancel">放弃所有修改？</template>
  提交
</button>
```

与 `x-slot` 的分工：**`x-slot:名` 是内容/出口名**（这份内容投影到组件的哪个插槽），**`x-slots="组件名"` 是归属**（这份内容属于宿主上的哪个覆盖物）——两者一个冒号、一个等号，不要混淆。覆盖物宿主的**裸子节点（按钮标签等）永不参与收集**，内容必须显式声明；插槽本身的语义见 [x-slot](./x-slot.md)。

## 快速入门

demo 里有三组按钮，各演示一种归属形态：

1. **上面按钮「打开（内容标记投影）」**——单消费者，标记直写宿主子级：按钮文字始终留在按钮上，点开后对话框正文是标记内那份内容（覆盖了 fallback），关闭后按钮完好；
2. **中间按钮「打开（无出口组件）」**——组件未声明任何插槽，显式提供的内容被警告丢弃，对话框显示组件固定内容；
3. **下面两个「多消费者」按钮**——每个按钮都声明 save + cancel 双 `x-dialog`，内容各套 `x-slots` 容器；打开谁就只投影谁的那份内容，互不串台。

**试试看**：把上面按钮里的 `<div x-slot>` 改成裸文本（去掉标记），再点开——对话框会退回组件默认内容，按钮文字不被收集。

## 指南

### 指令值

`x-slots` 没有修饰符，值只有一个含义——**归属的覆盖物组件名**：

| 形态                             | 用在哪             | 说明                                                             |
| -------------------------------- | ------------------ | ---------------------------------------------------------------- |
| `x-slots="<覆盖物组件名>"`       | 覆盖物宿主的直接子级 | 归属容器：容器内子节点 = 该覆盖物的默认段（容器自身不进运行 DOM） |
| `x-slot:名`（同一位置）          | 覆盖物宿主的直接子级 | 内容标记：决定投影进组件的哪个插槽——**不是归属**                 |
| `<div x-slots>`（无值）          | —                  | 缺归属名 → 警告 + 容器内容丢弃                                    |

- `x-slots` 的值**必须命中宿主上某个 `x-dialog:名称`**，否则警告 + 丢弃；
- 作用域插槽的两侧语法（出口侧 / 内容侧）在覆盖物路径**照常生效**，见 [x-slot · 作用域插槽](./x-slot.md#作用域插槽)。

### 归属规则

| 宿主形态                              | 规则                                                                                             |
| ------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 单个 `x-dialog`（宿主只有一个消费者） | 内容标记**直写宿主子级**即可，无需容器：`<button x-dialog:a="…"><div x-slot>正文</div>打开</button>` |
| 多个 `x-dialog` 共用一个宿主          | 内容**必须**各套 `x-slots="组件名"` 容器：`<template x-slots="save">…</template>`——容器内裸子节点 = 该覆盖物的默认段 |
| 想用宿主标签当默认内容（旧写法）      | **已废止**：标签永远留在按钮上，覆盖物显示组件 fallback                                         |

- 容器与内容标记都**不进运行 DOM**（编译期剪枝，打开时从模板克隆投影）——按钮标签不受任何影响；
- 归属**只认宿主直接子级**的容器（容器嵌套容器 → 警告 + 忽略内层，其子节点并入外层组）；
- 同宿主多消费者却写了**裸标记**（没套容器）→ 无法判定归属，**警告 + 丢弃**；
- `x-component` 与 `x-dialog` **不能写在同一个元素上**（组件化身与弹窗声明点对子节点的定位互斥），警告后组件让位。

```html
<!-- ✗ 多消费者 + 裸标记：无法判定归属，警告丢弃 -->
<button x-dialog:save="ui.save" x-dialog:cancel="ui.cancel">
  <div x-slot>给谁的？</div>
  提交
</button>

<!-- ✓ 各套容器分家 -->
<button x-dialog:save="ui.save" x-dialog:cancel="ui.cancel">
  <template x-slots="save">保存当前草稿？</template>
  <template x-slots="cancel">放弃所有修改？</template>
  提交
</button>
```

### 校验与警告

| 控制台提示                                                       | 处理方式                                                     |
| ---------------------------------------------------------------- | ------------------------------------------------------------ |
| `x-slots: 归属容器缺少覆盖物组件名`                             | 容器写成了 `x-slots` / `x-slots=""`——补上覆盖物组件名        |
| `x-slots: 宿主上无名为 "xxx" 的覆盖物消费者`                    | 容器名与宿主上的 `x-dialog:名` 不匹配——改对名字             |
| `x-slots: 归属容器 "xxx" 的宿主上无覆盖物消费者`                | 写在了没有 `x-dialog` 的元素上——挪到消费者宿主              |
| `x-slots: 归属容器 "xxx" 重复`                                  | 同名容器写了两处——合并内容，删除一处容器                    |
| `x-slots: …未被归属容器包裹的内容无法判定归属…`                 | 多消费者的宿主写了裸标记——用 `x-slots="组件名"` 分别包裹     |
| `x-slots: 归属容器内部的嵌套 x-slots 已忽略`                    | 容器里又套了容器——把内容标记提到宿主直接子级                |
| `覆盖物组件 "xxx" 未声明任何 x-slot 出口`                       | 给无插槽的组件硬塞内容——删内容，或给组件补出口              |
| `x-component: 宿主元素同时声明了覆盖物消费者`                   | 同一元素写了 `x-component` + `x-dialog`——拆到两个元素        |

覆盖物路径的警告会带 `x-dialog:名称: ` 前缀（如 `x-dialog:confirm: …`），便于定位是哪个消费者的问题。

## 注意事项

- **`x-slots` 与 `x-slot` 是两个东西**：`x-slot:名` 的冒号段恒为**出口/内容名**，归属只写在 `x-slots="组件名"`（等号）上；
- **宿主裸子节点永不收集**：按钮标签等永远留在宿主——内容要么显式写标记（单消费者），要么套归属容器（多消费者）；
- **容器不进运行 DOM**：编译期剪枝，运行时从模板克隆投影，不需要也不能给容器写样式；
- **只认宿主直接子级**：容器嵌容器、内容标记写深一层都会被警告并按普通内容处理；
- **继续阅读**：插槽声明、内容投影、动态插槽见 [x-slot](./x-slot.md)；内容里叠加默认内容见 [x-super](./x-super.md)；弹窗用法见 [x-dialog](./x-dialog.md)。
